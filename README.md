# 수서로 2.1

**학교도서관 사서를 위한, 내 PC에서 쓰는 도서 구입 도우미.**

책을 담고, 예산을 확인하고, 발주서를 저장하세요. 가입이나 서버 준비 없이 시작합니다.

이 작업본은 **2.1.0 로컬 검토용**입니다. 아래 다운로드 페이지에는 공개된 버전이 표시되며, 이 문서 수정만으로 새 버전이 배포되지는 않습니다.

## 설치하고 시작하기

1. [최신 공개 버전 다운로드](https://github.com/buildergarlic/suseoro/releases/latest)에서 해당 버전의 **Suseoro-Setup-버전.exe**를 받습니다.
2. 설치한 뒤 바탕화면의 **수서로**를 엽니다.
3. **ISBN 추가** 또는 **파일 가져오기**로 책을 담고 **발주서 저장**을 누릅니다.

Windows 10/11 64비트용입니다. 설치 파일에는 Python, 화면, 한국어·영어 PDF 문자 인식 도구가 포함됩니다. Windows 화면 엔진인 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)가 필요한 환경에서는 설치하거나 시작 메뉴의 **수서로 (브라우저)**를 이용하세요. 설치 파일의 코드 서명 인증서는 아직 적용하지 않았습니다.

설치 권한이 제한된 환경에서는 같은 릴리스의 Portable ZIP을 풀어 `Suseoro.exe`를 실행할 수 있습니다. 자료는 두 실행 방식 모두 현재 Windows 사용자의 별도 자료 폴더에 저장합니다.

## 사서에게 필요한 기능

| 할 일 | 수서로에서 하는 방법 |
|---|---|
| 예산 관리 | 기본 1,500만 원, 목록별 예산·할인율 설정, 선택금액과 잔액 즉시 계산 |
| 책 찾기 | ISBN 10/13 검증 후 해당 판본의 무료 서지정보 조회, 직접 입력·수정 |
| 책 고르기 | 구입 선택·보류, 수량·가격·우선순위·학생/교사 요청·메모 수정, 삭제 취소 |
| 편하게 읽기 | 글자 크기 16·18·20, 간결한 행 간격, Ctrl+F 도서 검색, 목록 옆 오른쪽 편집 |
| 추천 목록 정리 | Excel, CSV, PDF, HWP, HWPX, DOCX, 텍스트를 미리보기 후 가져오기 |
| 잘못된 값 확인 | 열 연결 수정, 원문·출처 보존, 불확실한 도서와 미확인 가격 표시 |
| 중복 구입 확인 | 목록 내 중복 및 업로드한 학교 소장 자료와 비교 |
| 발주서 작성 | 기본 Excel, 학교 Excel 양식, CSV, 인쇄용 파일 저장 |
| 자료 보관 | 자동 저장, 백업·복원, 업데이트 후에도 자료 유지 |
| 새 버전 사용 | 설치형은 새 버전을 자동으로 내려받고 정상 종료할 때 설치, 설정에서 끄기 가능 |

가격 미확인, 내용 확인 필요, 잘못된 ISBN, 예산 초과 상태는 발주서를 만들기 전에 해결하도록 안내합니다. 한 권의 할인 후 금액을 원 단위 반올림한 뒤 수량을 곱합니다. 학생·교사 요청, 주제, 우선순위를 기록해 필요한 책을 고르는 일을 돕습니다.

오른쪽 위 **글자 크기**에서 16·18·20을 선택하고 **간결하게**로 행 간격을 바꾸세요. 목록 화면에서 `Ctrl+F`를 누르면 도서 검색란으로 이동합니다. 책 제목이나 **수정**을 누르면 오른쪽 편집 영역이 열립니다. 변경한 책 정보는 **저장**으로 확정합니다.

## ISBN 정보와 파일 인식 범위

- **Open Library**는 인증키 없이 이용합니다. 국내 도서 정보가 부족할 수 있습니다.
- **국립중앙도서관 ISBN 서지정보 API**는 회원가입 → 인증키 신청 → 담당자 승인 후 이용합니다. **ISBN 추가 → 국내 도서 조회 설정** 또는 **학교 설정 · 백업**에서 승인된 키를 한 번 등록하세요. [신청·관리](https://www.nl.go.kr/NL/contents/N31101020000.do) · [공식 API 안내](https://www.nl.go.kr/NL/contents/N31101030500.do)
- ISBN이 일치하는 판본만 채웁니다. 찾지 못한 정보는 직접 입력할 수 있습니다. API의 예정가격은 확인 대상으로 표시하며, 전자책 판매가격을 종이책 정가로 사용하지 않습니다.
- Excel의 표, 문서의 표와 텍스트, PDF의 위치 정보를 분석합니다. 스캔 PDF는 한국어·영어 문자 인식을 시도합니다. 흐릿한 스캔, 복잡한 편집, 암호화 문서, 일부 구형 HWP는 완전하게 해석되지 않을 수 있습니다. 미리보기에서 원문과 값을 확인하세요.
- 추천 양식의 위쪽 안내문·빈 행·병합된 여러 줄 머리글·반복 머리글·합계를 더 잘 구분합니다. 시트마다 열 이름이 달라도 원문과 위치를 확인하며 연결할 수 있습니다. 건너뛴 행과 인식 경고를 살피고, 수식 가격이나 서로 다른 ISBN이 있는 행은 직접 확인하세요.
- 학교별 출력 양식은 **.xlsx**를 지원합니다. HWP/HWPX/PDF는 추천 자료 입력에 사용하며, 해당 형식의 학교 양식에 직접 출력하지는 않습니다. 인쇄용 파일은 브라우저에서 열어 PDF로 저장할 수 있습니다.

책 아래 **알라딘 ↗**, **국립중앙도서관 ↗**는 유효한 ISBN으로 외부 사이트를 검색합니다. 상세 상품을 확정하거나 구매를 전송하는 버튼은 아닙니다. 알라딘은 국내도서 검색, 국립중앙도서관은 소장자료 검색이므로 결과가 없을 수 있습니다. 제목·판본·정가를 확인한 뒤 목록을 수정하세요.

알라딘 OpenAPI는 신규 인증키 발급이 **2026년 9월 4일** 종료됐고 기존 API도 **10월 30일** 종료 예정이어서 신규 연동하지 않습니다. 검색 링크는 API 연동과 별개입니다. [공식 종료 공지](https://blog.aladin.co.kr/openapi/17486624)

이번 검토본에서는 국립중앙도서관의 실제 승인키로 성공 조회를 검증하지 않았습니다. **인증키 등록됨**은 저장 상태이며 연결 성공을 보장하지 않습니다. 오류 응답 처리와 판본 일치 검사는 테스트했고, 실제 조회 결과는 등록 후 확인해야 합니다.

## 자료 보관

**2.0.2부터 자동 업데이트를 지원합니다.** 설치형 수서로는 새 버전을 확인해 검증된 설치 파일을 미리 내려받습니다. 작업을 마치고 수서로를 닫으면 조용히 설치하고, 다음 실행부터 새 버전을 사용합니다. 작업 중 창을 자동으로 닫지 않습니다. **학교 설정 · 백업**에서 자동 업데이트를 끄거나 지금 업데이트할 수 있습니다. 2.0.0/2.0.1 사용자는 새 설치 파일이나 기존 **업데이트 확인 → 업데이트 설치**로 한 번 전환해야 합니다. 무설치판은 자동 설치 대상이 아닙니다.

수서 목록, 소장 자료, 업로드 원본, 학교 양식은 `%LOCALAPPDATA%\Suseoro`에 저장합니다. ISBN 조회 시 ISBN을 제공기관에 보내고, 업데이트 확인 시 GitHub에 접속합니다. 문서 전체를 외부 AI 서비스에 전송하지 않습니다.

**학교 설정 → 백업 파일 저장**으로 자료를 보관하세요. 백업은 목록·소장 자료·학교 양식·추천 원본을 포함하며 API 인증키는 제외합니다. 복원 전 현재 자료를 별도 백업합니다. 백업에도 요청자 등 개인정보가 포함될 수 있으므로 학교 자료와 동일하게 관리하세요. 앱 삭제 후에도 자료 폴더는 보존합니다.

1.x의 파일은 자동으로 덮어쓰거나 변환하지 않습니다. 이전 수서 목록을 Excel/CSV로 저장한 후 2.0에서 가져오세요.
