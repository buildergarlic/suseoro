# 설치 방법

## 1. 사서에게 전달할 파일

- `학교도서관_수서자동화_포터블_Ver_1.0.zip` 파일 1개만 전달합니다.
- 이 ZIP 파일 안에 실행 파일, 설명서, 샘플, 작업 폴더가 모두 들어 있습니다.

## 2. 사서 PC에서 설치 없이 실행하는 방법

1. 받은 `학교도서관_수서자동화_포터블_Ver_1.0.zip` 파일을 PC에 저장합니다.
2. 저장 위치는 `바탕화면` 또는 `문서` 폴더처럼 찾기 쉬운 곳이면 됩니다.
3. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 `압축 풀기` 를 합니다.
4. 압축을 풀면 `학교도서관_수서자동화_포터블_Ver_1.0` 폴더가 생성됩니다.
5. 그 폴더 안의 `start.cmd` 를 더블클릭합니다.
6. 브라우저가 자동으로 열리지 않으면 주소창에 `http://127.0.0.1:3847` 를 직접 입력합니다.
7. 작업을 마친 뒤 프로그램을 완전히 종료하려면 `stop.cmd` 를 실행합니다.

## 3. 압축을 푼 뒤 폴더 안에 있어야 하는 항목

- `SuseoroAI.exe`
- `start.cmd`
- `stop.cmd`
- `config`
- `manual`
- `samples`
- `workspace`
- `portable_tesseract`

## 4. 꼭 지켜야 할 점

- `SuseoroAI.exe` 파일 하나만 따로 옮기면 안 됩니다.
- 압축을 푼 폴더 전체를 그대로 유지해야 정상 작동합니다.
- 가능하면 공유폴더에서 바로 실행하지 말고, 각자 PC의 로컬 폴더로 먼저 복사한 뒤 실행합니다.

## 5. SmartScreen 경고가 나올 때

1. `추가 정보` 를 누릅니다.
2. `실행` 을 누릅니다.

## 6. 같은 프로그램을 다른 사서도 똑같이 쓰게 하려면

1. 같은 `학교도서관_수서자동화_포터블_Ver_1.0.zip` 파일을 전달합니다.
2. 사서마다 자기 PC에 압축을 풀고 `start.cmd` 를 실행하게 안내합니다.
3. 같은 설정을 그대로 쓰려면 ZIP 안의 `config/settings.json` 이 포함된 상태 그대로 전달하면 됩니다.

## 7. 기존 작업을 이어서 쓰는 방법

- 작업 내용은 `workspace` 폴더에 저장됩니다.
- 새 버전으로 바꿀 때는 예전 폴더의 `workspace` 폴더를 새 폴더에 복사하면 됩니다.
- 필요하면 `config/settings.json` 도 함께 복사합니다.

## 8. 사서에게 가장 짧게 안내하는 문장

- `압축을 풀고, 폴더 안의 start.cmd만 누르면 됩니다.`
- `실행 파일 하나만 옮기지 말고 폴더 전체를 그대로 사용하세요.`
