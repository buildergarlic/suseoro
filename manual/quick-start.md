# 빠른 시작 1장 가이드

## 1. 실행

1. `학교도서관_수서자동화_포터블_Ver_1.0.zip` 압축을 풉니다.
2. 폴더 안의 `start.cmd` 를 더블클릭합니다.
3. 브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:3847` 를 직접 입력합니다.

## 2. 학교 만들기

1. 첫 화면에서 학교 이름을 입력합니다.
2. 학교 작업공간이 만들어지면 해당 학교 화면으로 이동합니다.

## 3. 회차 만들기

1. 연도 예: `2026`
2. 회차 예: `1차`
3. `회차 생성` 을 누릅니다.

## 4. 파일 올리기

1. `DLS 소장목록 업로드` 에서 DLS 리스트 반출 엑셀을 올립니다.
2. `추천목록 업로드` 에서 추천 엑셀과 PDF를 함께 올립니다.
3. ISBN만 있는 경우 `ISBN 일괄 입력` 에 붙여넣습니다.
4. 제목과 저자만 있는 경우 `제목 | 저자 입력` 에 한 줄씩 넣습니다.

## 5. 통합 실행

1. `통합 분석 실행` 버튼을 누릅니다.
2. 추천목록 통합, 중복 추천 집계, 복본 검사, 서지 보강이 수행됩니다.

## 6. 검수

1. `최종구매후보` 에서 바로 구매할 책을 확인합니다.
2. `복본-기소장` 에서는 기존 소장과 겹친 책을 확인합니다.
3. `검토필요` 에서는 파싱 품질이 낮거나 서지 정보가 불충분한 책을 확인합니다.
4. 필요한 경우 제목, 저자, 출판사, ISBN을 수정하고 `행 저장` 을 누릅니다.
5. `ISBN/서지 다시 조회` 로 알라딘 후보를 다시 불러올 수 있습니다.

## 7. 최종 엑셀 만들기

1. 검수 화면에서 `최종 수서목록 엑셀 생성` 을 누릅니다.
2. `최종 엑셀` 버튼으로 결과 파일을 내려받습니다.
3. `검수 엑셀` 은 중간 작업 이력 보관용입니다.

## 8. 자주 생기는 상황

- 브라우저가 자동으로 안 열리면 주소를 직접 입력합니다.
- SmartScreen 경고가 뜨면 `추가 정보 -> 실행` 을 누릅니다.
- 알라딘 API 키가 없으면 ISBN 자동보강만 꺼지고 나머지 기능은 그대로 사용 가능합니다.
- PDF가 스캔본이면 시간이 더 걸릴 수 있습니다.
