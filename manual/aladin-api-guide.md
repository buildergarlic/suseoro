# 알라딘 API 키 설정 가이드

## 1. API 키 준비

알라딘 TTB API 키를 발급받아야 ISBN 자동보강과 제목 검색이 동작합니다.

참고:

- 상품 조회 API 안내: https://blog.aladin.co.kr/openapi/5353294
- 검색 API 안내: https://blog.aladin.co.kr/openapi/5353290

## 2. 앱에 입력하는 위치

1. 상단 메뉴의 `설정` 으로 이동합니다.
2. `알라딘 TTB API 키` 칸에 키를 붙여넣습니다.
3. `설정 저장` 을 누릅니다.

저장 위치는 `config/settings.json` 입니다.

## 3. 어떤 작업에 쓰이나요

- ISBN만 입력된 항목의 기본 서지 자동 채움
- 제목 + 저자만 있는 항목의 후보 검색
- 추천목록에서 ISBN이 비어 있는 경우 보강 시도

## 4. 조회가 실패할 때 확인할 것

- API 키 오탈자
- 인터넷 연결
- 알라딘 Open API 응답 지연

## 5. 키가 없어도 가능한 기능

- 추천목록 통합
- 복본 검사
- 검수 화면에서 수동 수정
- 최종 수서목록 엑셀 출력
