# 강사용 설명 순서

## 15분 시연 흐름

### 1. 시작 2분

- 이 프로그램은 학교별 작업 폴더에 데이터를 쌓아 가는 로컬 웹앱입니다.
- 설치형이 아니라 압축 해제 후 실행 파일만 누르면 됩니다.
- DLS 소장목록과 여러 추천도서 목록을 합쳐 복본 없는 최종 수서목록을 만듭니다.

### 2. 학교 생성 1분

- 첫 화면에서 학교 이름을 입력합니다.
- 학교별 폴더가 자동으로 만들어진다는 점을 보여 줍니다.

### 3. 회차 생성 1분

- 연도와 회차를 입력하고 세션을 만듭니다.
- 회차별로 검수 결과와 최종 엑셀이 분리 저장된다고 설명합니다.

### 4. 파일 업로드 3분

- DLS 소장목록 엑셀 먼저 업로드
- 추천 엑셀 2개 이상 업로드
- PDF 예시 1개 업로드
- ISBN만 붙여넣기
- 제목 | 저자 입력 예시 추가

### 5. 통합 실행 2분

- 통합 분석 실행
- 추천목록 통합, 중복 추천 집계, 복본 검사, 알라딘 조회가 동시에 일어난다고 설명

### 6. 검수 화면 4분

- `최종구매후보` 탭: 바로 선택 가능한 책
- `복본-기소장` 탭: 기존 소장과 겹친 책
- `검토필요` 탭: 애매하거나 OCR 품질이 낮은 책
- 한 행을 직접 수정하고 저장
- `ISBN/서지 다시 조회` 와 `후보 적용` 시연

### 7. 최종 엑셀 2분

- `최종 수서목록 엑셀 생성`
- 샘플 형식과 동일한 열 순서로 나온다는 점 확인
- 같은 폴더를 다음 회차에도 그대로 쓴다는 점 강조

## 핵심 설명 문장

- 설치가 아니라 압축만 풀고 시작 파일만 누르면 됩니다.
- 학교별 데이터는 모두 `workspace` 폴더 안에 남습니다.
- DLS 소장목록을 먼저 올려야 복본 검사가 정확합니다.
- ISBN이 없으면 제목과 저자로도 후보를 찾을 수 있습니다.
- 프로그램이 애매한 책을 자동으로 빼지 않고 `검토필요` 로 보내기 때문에 마지막 판단은 사서가 직접 할 수 있습니다.

## 사서에게 파일을 전달할 때 이렇게 설명하세요

### 1. 강사가 먼저 준비할 파일

- 사서에게는 가능하면 `학교도서관_수서자동화_포터블_Ver_1.0.zip` 파일 1개만 전달합니다.
- 전달 방법은 USB, 메신저, 이메일, 학교 공용 드라이브 중 편한 것을 쓰면 됩니다.
- 말로는 아주 짧게 `압축 풀고 start.cmd만 누르면 됩니다.` 라고 안내하면 됩니다.

### 2. 사서에게 꼭 같이 말해 줄 점

- `도서관수서자동화.exe` 파일만 따로 보내면 안 됩니다.
- 압축을 풀었을 때 나온 폴더 전체를 그대로 둬야 정상 실행됩니다.
- 가능하면 공유폴더에서 바로 실행하지 말고, 각자 자기 PC의 `바탕화면` 이나 `문서` 폴더로 먼저 복사한 뒤 실행하도록 안내합니다.

### 3. 사서 PC에서 복사하고 실행하는 순서

1. 받은 `학교도서관_수서자동화_포터블_Ver_1.0.zip` 파일을 PC에 저장합니다.
2. 저장 위치는 `바탕화면` 이나 `문서` 폴더처럼 찾기 쉬운 곳이면 됩니다.
3. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 `압축 풀기` 를 합니다.
4. 압축을 풀면 `학교도서관_수서자동화_포터블` 폴더가 생깁니다.
5. 그 폴더 안에 들어가서 `start.cmd` 를 더블클릭합니다.
6. 브라우저가 자동으로 안 열리면 주소창에 `http://127.0.0.1:3847` 를 직접 입력합니다.
7. 작업을 마친 뒤 프로그램을 완전히 끄고 싶으면 같은 폴더의 `stop.cmd` 를 누릅니다.

### 4. 압축을 푼 뒤 폴더 안에서 보이면 정상인 파일

- `SuseoroAI.exe`
- `start.cmd`
- `stop.cmd`
- `config` 폴더
- `manual` 폴더
- `samples` 폴더
- `workspace` 폴더
- `portable_tesseract` 폴더가 있으면 PDF 스캔본 처리에 도움이 됩니다.

### 5. 사서에게 특히 쉽게 설명할 문장

- 따로 설치하는 프로그램이 아닙니다.
- 압축을 푼 폴더를 통째로 두고 `start.cmd` 만 실행하면 됩니다.
- 작업한 내용은 같은 폴더 안의 `workspace` 폴더에 자동 저장됩니다.
- 그래서 나중에 PC를 바꾸거나 새 버전을 받을 때는 `workspace` 폴더를 같이 옮기면 됩니다.

### 6. 새 버전으로 바꿀 때 설명하는 방법

1. 새로 받은 ZIP 파일을 다른 폴더에 먼저 압축 풉니다.
2. 예전에 쓰던 폴더에서 `workspace` 폴더를 찾습니다.
3. 필요하면 `config\settings.json` 도 함께 복사합니다.
4. 그 파일과 폴더를 새 버전 폴더 안에 덮어넣습니다.
5. 새 폴더의 `start.cmd` 를 실행합니다.

### 7. 강사가 한마디로 정리해서 안내할 때

- `받은 ZIP 파일을 압축 풀고, 폴더 안의 start.cmd를 누르면 바로 실행됩니다.`
- `실행 파일 하나만 옮기지 말고, 압축을 푼 폴더 전체를 그대로 사용하세요.`
- `기존 작업을 이어서 쓰려면 예전 폴더의 workspace 폴더를 새 폴더로 복사하면 됩니다.`

## 예상 질문과 답변

### 인터넷이 끊기면 어떻게 되나요

- 통합, 중복 검사, 엑셀 출력은 계속 됩니다.
- 알라딘 조회만 잠시 실패할 수 있고 나중에 다시 눌러 재조회할 수 있습니다.

### 학교마다 따로 설치해야 하나요

- 설치가 아니라 폴더 단위 실행입니다.
- 압축을 풀고 `start.cmd` 만 실행하면 됩니다.

### 새 버전 배포는 어떻게 하나요

- 기존 `workspace` 폴더를 보존한 채 앱 폴더만 교체하면 됩니다.
