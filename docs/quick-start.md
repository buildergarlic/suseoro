# 수서로, 이것만 알면 됩니다

## 1. 책을 담으세요

**ISBN 추가**에서 ISBN을 입력하고 조회하세요. 제목·저자·출판사 정보를 확인하고 정가와 수량을 넣은 뒤 저장합니다. ISBN을 모르면 **직접 추가**를 사용하세요.

기관에서 받은 목록이 있다면 **파일 가져오기**를 누르세요. 미리보기에서 제목·저자·ISBN·가격 열이 맞는지 보고 필요한 행만 가져옵니다. 연결이 어긋나면 열 이름을 다시 지정합니다. ISBN만 있는 행은 **ISBN으로 빈 정보 채우기**를 사용할 수 있습니다. 불확실한 행은 확인 대상으로 남습니다.

파일당 50 MB까지 지원합니다. 인식이 어려운 파일은 표를 Excel로 저장하거나 PDF 화질을 높여 다시 가져오세요. 스캔 문서에서 추출한 ISBN과 가격은 꼭 확인하세요.

## 2. 예산 안에서 고르세요

화면 위의 **예산·선택금액·남은 예산**을 보세요. 기본 예산은 1,500만 원이며 목록 설정에서 바꿀 수 있습니다. 체크한 책만 발주서에 들어갑니다. 체크를 풀면 보류 상태로 남습니다.

책을 눌러 가격·수량·주제·학생/교사 요청·우선순위·메모를 수정하세요. 삭제를 잘못했다면 바로 표시되는 **되돌리기**를 누르세요. 가격이 없으면 미확인 상태로 표시합니다.

학교의 최신 전체 소장 도서 목록을 **소장 자료**로 가져오면 이미 소장한 도서를 표시합니다. 새 소장 자료를 가져오면 이전 소장 자료가 교체됩니다. 서로 다른 유효 ISBN의 판본은 같은 제목이어도 별도로 판단합니다.

## 3. 발주서를 저장하세요

**확인 필요** 도서의 내용과 정가를 확인하고 예산 초과를 해소하세요. **발주서 저장**에서 기본 Excel 또는 학교 Excel 양식을 선택합니다. CSV, 인쇄용 파일도 가능합니다. 인쇄용 파일은 내려받아 브라우저에서 열고 인쇄하거나 PDF로 저장하세요.

학교 양식은 [양식 안내](school-templates.md)를 참고하세요. 제출 전에 학교명·금액·수량과 합계를 한 번 확인하세요.

## 가끔 필요한 일

- **학교 설정:** 학교명과 선택 사항인 국립중앙도서관 인증키를 저장합니다.
- **백업 파일 저장:** 다른 PC로 옮기거나 중요한 발주를 마친 뒤 백업을 보관합니다. 인증키는 새 PC에 다시 등록합니다.
- **백업 불러오기:** 현재 전체 자료를 선택한 백업으로 교체합니다. 교체 직전 자료는 자료 폴더의 backups에 자동 보관됩니다.
- **업데이트 확인:** 새 버전이 있으면 설치 버튼을 누릅니다. 자료는 설치 폴더와 따로 보관됩니다.
- **수서로 종료:** 브라우저 방식으로 실행했다면 학교 설정의 이 버튼으로 프로그램을 종료한 뒤 탭을 닫습니다.

자료 저장 위치: Windows 탐색기의 주소창에 `%LOCALAPPDATA%\Suseoro`를 입력하세요. 이동·복사 전 수서로를 종료하세요.
