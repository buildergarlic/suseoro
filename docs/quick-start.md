# 수서로 2.2.0, 이것만 알면 됩니다

수서로는 **책을 모으고 → 구입할 책을 고르고 → 발주서를 저장하는** 프로그램입니다. 책을 고르는 기준과 최종 결정은 사서 선생님이 정합니다.

[그림으로 보는 쉬운 안내](visual-guide.html) · [자세한 사용설명서](user-guide.md)

프로그램에서는 왼쪽 아래 **사용설명서**를 누르면 이 안내를 볼 수 있습니다. 인터넷 없이 읽을 수 있고, **닫기** 또는 `Esc`로 작업하던 목록에 돌아옵니다. 2.0.1부터 제공하는 기능입니다.

기본 글자는 **16px**입니다. 오른쪽 위 **글자 크기**에서 **A− / A+**를 누르거나 **16·18·20·22·24px**를 고르세요. **간결하게**는 글자 크기를 유지하고 도서 행의 여백을 줄입니다. 두 설정은 이 PC에 저장되어 다음 실행에도 복원되며, 기존에 저장한 크기는 유지합니다. 창 가장자리를 끌어 넓히거나 **최대화**해도 됩니다. 큰 글자로 열이 다 보이지 않으면 표 안의 가로 스크롤을 이용하세요. 목록에서 `Ctrl+F`를 누르면 도서 검색란으로 이동합니다.

## 1. 책을 담으세요

**ISBN 추가**에서 ISBN을 한 줄에 하나씩 입력하고 **조회하고 추가**를 누르세요. 한 번에 최대 100개를 조회하며, **일치하는 책을 찾으면 바로 목록에 추가합니다.** 창을 닫은 뒤 책 제목이나 **수정**을 눌러 정가·수량을 확인하고 **저장**하세요. ISBN을 모르면 **＋ 직접 추가**를 사용합니다.

국내 도서를 찾기 어렵다면 같은 창의 **국내 도서 조회 설정 → 국립중앙도서관 인증키 등록**을 펼치세요. **인증키 신청 안내 ↗**에서 회원가입·신청·담당자 승인을 거쳐 받은 키를 넣고 **인증키 저장**을 누릅니다. 저장만으로 승인이나 연결 성공이 확인되지는 않습니다. 실제 승인키 성공 조회는 아직 검증하지 않았습니다.

유효한 ISBN이 있으면 알라딘 공개 상품 페이지에서 ISBN이 일치하는 표지를 우선 표시합니다. OpenAPI나 API 키 없이 동작하며, 실패 시 Open Library·Google Books 조회와 자동 재시도를 거쳐 **표지 재조회** 버튼을 제공합니다. ISBN이 없거나 잘못되면 **표지 없음**으로 표시합니다. 표지 조회 시 해당 ISBN을 외부 제공기관에 전송합니다. 표지는 참고용이므로 상품·판본·정가는 실제 ISBN과 정보로 확인하세요.

책 아래 **알라딘 ↗ / 국립중앙도서관 ↗**는 ISBN 검색을 엽니다. 같은 판본인지와 정가를 확인하세요. 검색 결과나 재고를 보장하지 않으며 주문을 전송하지 않습니다. 알라딘 신규 API 키 발급은 2026년 9월 4일 종료됐고 기존 API도 10월 30일 종료 예정입니다. 이 검색 링크는 API 연결 없이 이용합니다. [공식 공지](https://blog.aladin.co.kr/openapi/17486624)

기관에서 받은 목록이 있다면 **파일 가져오기 → 추천도서 목록**에서 여러 파일을 함께 선택하세요. 파일마다 제목·저자·ISBN·정가 열이 맞는지 봅니다. 연결이 어긋났다면 **열 연결 확인**을 펼쳐 연결한 뒤 **열 연결 적용**을 누르세요. 이 작업은 원본을 다시 읽으므로, **열 연결을 먼저 하고 개별 책을 수정**하세요.

그다음 불필요한 행은 **×**로 빼고, **상세 → 원문 보기**가 제공되는 행은 원문과 비교하세요. **같은 책 합치기**를 켜고 **○건 가져오기**를 누르면 출처와 원문을 보존해 한 번에 통합합니다. 합쳐도 구입 수량은 늘리지 않습니다. 제목·저자·출판사와 가격이 갖춰진 도서는 ISBN 없이도 진행할 수 있습니다. **ISBN으로 빈 정보 채우기**는 선택 기능으로, 한 번에 최대 50권을 조회하며 기존 입력값을 유지합니다.

파일당 50 MB까지 지원합니다. 스캔 PDF와 복잡한 한글 문서는 인식 결과를 꼭 확인하세요. 자세한 형식별 요령은 [파일 가져오기 안내](user-guide.md#8-추천도서-파일-가져오기)에 있습니다.

안내문이 길거나 머리글이 여러 줄인 실제 추천 양식도 인식을 보완했습니다. 건너뛴 안내·합계행과 원래 시트·행 위치를 확인하세요. 수식으로 된 가격과 서로 다른 ISBN이 함께 있는 행은 원문을 보고 결정합니다.

## 2. 예산 안에서 고르세요

화면 위의 **전체 예산·구입 선택 금액·남은 예산**을 보세요. 기본 예산은 1,500만 원이며 **목록 · 예산 설정**에서 바꿀 수 있습니다. **체크한 책만 발주서에 들어갑니다.** 체크를 풀면 책은 보류 상태로 남고 선택 금액에서 빠집니다.

책 제목이나 **수정**을 누르면 목록 오른쪽에 편집 영역이 열립니다. 정가·수량·분류·요청자·대상·우선순위·메모를 고친 뒤 **저장**하세요. **취소** 또는 `Esc`는 저장하지 않은 수정을 반영하지 않습니다. 우선순위는 판단을 돕는 기록이며 책을 자동으로 선택하지 않습니다. 삭제를 잘못했다면 화면의 최근 삭제 알림이 남아 있을 때 **삭제 취소**를 누르세요.

가격 미확인 도서는 선택 수량에는 포함되지만 선택 금액에서 빠집니다. **남은 예산이 보여도, 가격을 모두 확인하기 전에는 예상 잔액입니다.** 목록을 여러 개 만들면 예산도 각각 따로 계산합니다.

여러 권을 함께 처리하려면 **작업** 체크 또는 **검색·필터 결과 N건 전체 선택**으로 대상을 고르고 **서지 확인 완료·구입 선택·보류**를 누르세요. 작업 선택과 구입 체크는 별개입니다. ISBN 없는 책도 서지를 확인한 뒤 한꺼번에 확인 완료할 수 있지만, 잘못된 ISBN·가격 누락·불완전한 서지는 사유와 함께 남습니다. **되돌리기**는 이후 편집을 덮어쓰지 않고 최근 작업을 취소합니다.

학교의 최신 **전체 소장목록**은 **파일 가져오기 → 학교 소장목록**으로 가져오세요. **○건 가져오기**를 누르면 이전 소장목록 전체가 교체됩니다. 비교 결과는 **학교 소장**으로 표시되며 자동으로 구입에서 제외되지는 않습니다.

## 3. 발주서를 저장하세요

구입 선택한 책의 제목·정가·ISBN과 **확인 필요 표시**를 점검하고, 예산 초과를 해소하세요. **발주서 저장**에서 다음 중 하나를 선택합니다.

- **Excel:** 기본 양식 또는 학교의 `.xlsx` 양식으로 저장합니다.
- **CSV:** 다른 프로그램에서 편집하거나 업로드할 표를 저장합니다. 받는 시스템의 열 규칙은 별도로 확인하세요.
- **인쇄용:** `.html` 파일을 저장합니다. 브라우저로 열어 인쇄하거나 인쇄 메뉴에서 PDF로 저장합니다.

학교 양식은 [상세 사용설명서의 학교 양식 안내](user-guide.md#12-학교-excel-양식-사용하기)를 참고하세요. 제출 전에 학교명·구입 책·수량·정가·할인율·합계를 다시 확인합니다. **발주서 저장은 파일 작성이며, 서점에 주문을 전송하는 기능은 아닙니다.**

## 가끔 필요한 일

왼쪽 아래 **학교 설정 · 백업**을 누르면 다음 기능을 사용할 수 있습니다.

| 할 일 | 누를 버튼과 확인할 점 |
|---|---|
| 학교명 등록 | 학교 이름 입력 → **설정 저장** |
| 국내 ISBN 조회 보완 | 선택 사항인 국립중앙도서관 인증키 입력 → **설정 저장** |
| 자료 보관 | **백업 파일 저장**. 목록·소장목록·추천 원본·학교 양식을 포함하며 인증키는 제외합니다. |
| 다른 PC로 이동 | 기존 PC에서 백업 → 새 PC에서 **백업 불러오기** → 교체 안내 확인 → **이 백업으로 복원** |
| 백업 복원 | 현재 자료 전체가 교체됩니다. 복원 직전 자료는 자료 폴더의 `backups`에 자동 보관됩니다. |
| 새 버전 설치 | **업데이트 확인** → 새 버전이 있으면 **업데이트 설치** |
| 프로그램 종료 | **수서로 종료**. 브라우저 방식에서는 종료 안내를 확인한 뒤 탭을 닫습니다. |

자료 저장 위치는 Windows 탐색기 주소창에 `%LOCALAPPDATA%\Suseoro`를 입력하면 열 수 있습니다. 자료 폴더를 직접 이동·복사할 때는 먼저 수서로를 종료하세요.

설치형은 시작 시 또는 **업데이트 확인**으로 새 버전을 확인합니다. 자동 업데이트가 켜져 있으면 설치 파일을 내려받아 검증하고, 작업을 저장해 정상 종료한 뒤 설치합니다. 작업 중 강제로 닫히지 않으며 꺼 둔 자동 업데이트 선택도 유지합니다.

### 우리 도서관 소장 여부 확인

책 제목 바로 아래에서 **소장 중 · 중복**, **소장목록에 없음**, **소장 확인 전**, **소장 대조 불가**를 구분합니다. 소장 일치는 ISBN 또는 제목·저자 일치 근거를 함께 표시하며, **소장 중복** 필터로 해당 책만 볼 수 있습니다. 소장자료를 가져오지 않았다면 미소장으로 판정하지 않습니다. 목록 위 **소장목록 가져오기 / 갱신**으로 최신 DLS 소장자료를 올리세요. 결과는 업로드한 소장자료 기준이며 판본별 ISBN이 다르면 별도 도서로 취급합니다. 구입 선택 여부는 직접 결정합니다.
