# 수서로 v2 빠른 사용 설명서

> 추천자료를 넣으면 우리 도서관에 없는 책을 찾아주고, 승인·발주·납품 검수까지 이어서 도와드립니다.

수서로 v2는 별도 저장 버튼이 없습니다. 입력이나 선택을 마치면 자동으로 저장됩니다.

## 1. 로그인하고 작업 열기

1. 관리자가 알려준 수서로 주소를 브라우저에서 엽니다.
2. `학교 코드`, `아이디`, `비밀번호`를 입력합니다.
3. `내 수서 업무`에서 가장 위의 `이어 하기`를 누릅니다.

담당자는 자료·후보·견적·발주·검수를 처리하고, 검토자는 목록 확인·의견·승인·수정 요청만 할 수 있습니다.

## 2. 후보 만들기

1. 처음 사용할 때만 `우리 도서관 소장목록`을 등록합니다.
2. 추천도서 파일을 한 번에 끌어놓거나 선택합니다.
3. 파일별 처리 결과를 확인한 뒤 `우리 도서관에 없는 책 찾기`를 누릅니다.
4. `확인 필요`만 검토하고 `후보 확정하고 승인 요청`을 누릅니다.

### 사용할 수 있는 파일

| 자료 | 지원 형식 |
| --- | --- |
| 추천목록·견적서·납품명세서 | XLS, XLSX, XLSB, ODS, CSV, TSV, PDF, TXT, DOCX, HWPX, HWP |
| 소장목록 | DLS MARC 권장, DLS Excel 호환 |
| 직접 입력 | 복사한 텍스트 붙여넣기 |

처음 보는 표는 20행 미리보기와 함께 열 연결 화면이 열립니다. `제목`, `저자`, `ISBN`, `수량`, `단가`를 연결한 뒤 `이 양식 기억`을 선택하면 다음부터 자동으로 읽습니다.

파일 한 개가 실패해도 다른 파일은 계속 처리됩니다. 읽지 못한 행은 파일·시트·행 또는 PDF 페이지 정보와 함께 `확인 필요`에 남습니다.

## 3. 후보 확인과 승인

- `수서 후보`: 우리 도서관에 없는 것으로 판단된 책
- `확인 필요`: 제목·저자 유사, ISBN 없음, 판본 차이 등 사서 판단이 필요한 책
- `제외된 책`: ISBN이 정확히 일치하는 소장도서 등. 필요하면 되돌릴 수 있습니다.

검토자는 후보 수·예상 금액·예산·장서 기준일을 확인하고 `이 목록 승인` 또는 `수정 요청 보내기`를 누릅니다. 승인 요청 뒤 책 추가, 수량 증가, 승인 예산 초과가 생기면 다시 승인이 필요합니다.

## 4. 견적 비교와 발주

1. 업체 이름과 견적 파일을 넣고 `견적서 비교하기`를 누릅니다.
2. 여러 업체의 총액, 할인, 품절, 가격 누락, 목록 불일치를 비교합니다.
3. 문제가 없는 견적에서 `이 견적 사용`을 누릅니다.
4. `발주파일 받기`로 XLSX 파일을 내려받습니다.
5. 파일을 학교의 평소 방식으로 업체에 직접 전달한 뒤 `업체에 전달했어요`를 누릅니다.

수서로는 S2B·나라장터·업체에 주문을 자동 전송하지 않습니다. 예산을 넘겨도 책을 임의로 삭제하지 않고 조정 또는 재승인을 안내합니다.

## 5. 납품명세서와 바코드 검수

1. 도서가 도착하면 납품명세서를 넣고 `납품명세서 비교하기`를 누릅니다.
2. 누락·초과·수량·단가·ISBN·판본 차이를 확인합니다.
3. `바코드 검수 시작`을 누릅니다.
4. USB ISBN 스캐너로 계속 읽습니다. 스캔 사이에 마우스를 누를 필요가 없습니다.
5. 차이가 있으면 `업체에 확인`, `반품 예정`, `추가 납품 예정`, `정상 인정` 중 하나를 기록합니다.
6. 모든 책의 바코드 확인 또는 차이 처리 방침 지정 후 `검수 완료하고 작업 끝내기`를 누릅니다.

화면 상단의 세 숫자는 서로 다른 뜻입니다.

- `납품명세서 반영`: 명세서에서 확인한 수량
- `바코드 확인`: 실제 책을 스캔한 수량
- `처리 대기 차이`: 아직 방침을 정하지 않은 차이

## 6. 문제가 생겼을 때

| 화면 문구 | 처리 방법 |
| --- | --- |
| 열 연결 필요 | 미리보기에서 열을 연결하고 다시 읽기 |
| 읽지 못함 | 암호·손상 여부 확인 후 HWPX, PDF 또는 XLSX로 변환 |
| 목록 불일치·가격 누락·품절 | 해당 견적을 수정하거나 다른 견적 사용 |
| 다른 사용자가 수정함 | 최신 내용을 다시 불러온 뒤 내 변경을 재확인 |
| 스캔 결과를 확인할 수 없음 | 같은 책을 다시 읽으면 같은 요청으로 안전하게 재확인 |
| 완료할 수 없음 | 화면 아래에 표시된 미스캔 수량이나 미처리 차이 해결 |

원본 파일과 읽지 못한 행은 자동으로 삭제되지 않습니다. 학생·대출자·대출이력은 수집하지 않습니다.

## 가장 짧은 사용 순서

```text
추천자료 넣기
→ 없는 책 찾기
→ 확인 필요 처리
→ 승인 요청
→ 견적 비교
→ 발주파일 받기
→ 납품명세서 비교
→ 바코드 스캔
→ 작업 완료
```
