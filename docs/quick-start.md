# 수서로 첫 10분 따라 하기

**처음 써도 괜찮습니다.** 연습용 목록에서 책 한 권을 담고, 구입할지 고른 다음, 발주서와 백업 파일을 저장해 보겠습니다. 실제 서점에 주문이 전송되지는 않습니다.

<p class="start-action"><a href="#미션-1-내-연습-목록-만들기">첫 미션 바로 시작하기 →</a></p>

> **설명서를 화면 옆에 놓고 싶다면** 프로그램의 **사용설명서** 창에서 **새 창으로 열어 나란히 보기 ↗**를 누르세요. 한 단계씩 읽고 프로그램에서 그대로 따라 하면 됩니다. 창을 따로 띄우기 어렵다면 **작업 화면으로 돌아가기**로 연습한 뒤 **사용설명서**를 다시 열어도 됩니다.

## 시작 전: 화면에서 세 곳만 찾으세요

| 위치 | 보이는 이름 | 하는 일 |
|---|---|---|
| 왼쪽 위 | **내 구입 목록** · **새 목록 만들기** | 학기나 사업별로 목록을 만듭니다. |
| 왼쪽 가운데 | **이번 목록 예산** · **주요 작업** | 남은 예산을 보고 책 추가·파일 가져오기·발주서 저장을 합니다. |
| 오른쪽 | **도서 목록** | 책을 검색하고, **구입** 체크를 바꾸고, 제목을 눌러 수정합니다. |

창이 좁아 왼쪽 메뉴가 안 보이면 왼쪽 위 **☰ 메뉴 열기**를 누르세요. 글자가 작으면 왼쪽 메뉴 아래 **글자 크기 A+**를 누릅니다.

이제 아래의 **미션 1 → 6**을 순서대로 해 보세요. 각 미션의 **성공 신호**가 보이면 다음으로 넘어가면 됩니다.

## 미션 1. 내 연습 목록 만들기

1. 왼쪽 **새 목록 만들기**를 누릅니다.
2. **목록 이름**에 `연습용 도서 구입`, **예산 (원)**에 `50000`, **할인율 (%)**에 `0`을 입력합니다. 연도는 올해 값 그대로 둡니다. 숫자는 쉼표 없이 입력하세요.
3. **저장**을 누릅니다.

**성공 신호:** 왼쪽 **내 구입 목록**에 `연습용 도서 구입`이 생기고, 오른쪽 제목에도 같은 이름이 보입니다. 왼쪽 **이번 목록 예산**에는 전체 예산 **50,000원**이 표시됩니다.

**왜 연습 목록을 따로 만들까요?** 실제 구입 목록에 연습용 책이 섞이지 않기 때문입니다. 연습이 끝나면 왼쪽에서 원래 목록을 다시 선택하면 됩니다.

## 미션 2. ISBN 없이 책 한 권 담기

1. 오른쪽 도서 목록 아래 **＋ 직접 추가**를 누릅니다. 새 목록이라 비어 있다면 가운데의 **책 정보를 직접 입력할게요 →**를 눌러도 됩니다.
2. 다음 연습용 정보를 입력합니다.

   | 입력칸 | 넣을 값 |
   |---|---|
   | **책 제목** | `연습용 별빛 도서관` |
   | **저자** | `김연습` |
   | **출판사** | `예시출판` |
   | **ISBN** | 비워 둡니다. |
   | **정가 (원)** | `12000` |
   | **수량** | `1` |

3. **구입할 책으로 선택**이 체크된 것을 확인하고 **저장**을 누릅니다.

**성공 신호:** 도서 목록에 `연습용 별빛 도서관`이 한 줄 생깁니다. 왼쪽 **구입 선택 금액**은 **12,000원**, **남은 예산**은 **38,000원**입니다. ISBN을 비워도 제목·저자·출판사·정가를 입력했다면 연습을 계속할 수 있습니다.

> **버튼을 못 찾겠나요?** 왼쪽 **ISBN 추가 → ISBN 없이 직접 추가**로도 같은 창을 열 수 있습니다. 실제 ISBN이 있는 책은 **ISBN 추가**에 번호를 넣고 **조회하고 추가**를 누르면 됩니다.

## 미션 3. 구입과 보류 바꿔 보기

1. 방금 담은 책의 **구입** 체크를 끕니다. 이 체크는 도서 표의 **작업** 체크 옆에 있습니다.
2. 왼쪽 예산 숫자를 봅니다. **구입 선택 금액 0원**, **남은 예산 50,000원**으로 바뀝니다.
3. 책이 지워지지 않고 **보류**로 남아 있는지 확인한 뒤 **구입**을 다시 체크합니다.

**성공 신호:** 금액이 다시 **12,000원 / 38,000원**이 됩니다. **구입**은 발주서에 넣을 책을 고르는 체크이고, **작업**은 여러 책을 한꺼번에 고칠 때 쓰는 체크입니다. 두 체크는 서로 다릅니다.

## 미션 4. 저장된 책을 다른 화면에서 찾아보기

1. 왼쪽 **등록 자료 → 추천도서 목록**을 누릅니다.
2. **직접 입력** 그룹에서 `연습용 별빛 도서관`을 찾습니다. 검색칸에 `별빛`을 넣어도 됩니다.
3. 위쪽 **구입 목록으로 돌아가기**를 누릅니다.

**성공 신호:** 같은 책이 원래 구입 목록에 그대로 있습니다. 추천도서 목록은 **현재 구입 목록에 저장된 책을 출처별로 읽어 보는 화면**입니다. 파일을 가져온 뒤에는 기관명·파일명으로도 묶여 보이며, 같은 책을 두 곳에서 추천하면 각 출처에 표시해도 도서 수는 한 번만 셉니다.

## 미션 5. 발주서 한 장 저장하기

1. 왼쪽 **주요 작업 → 발주서 저장**을 누릅니다.
2. **저장 형식**에서 **Excel**을 그대로 선택하고, **발주서 양식**도 **수서로 기본 양식** 그대로 둡니다.
3. 창 아래 **발주서 저장**을 누릅니다.

**성공 신호:** Excel `.xlsx` 파일 다운로드가 시작됩니다. 저장된 파일을 열어 **책 제목·수량 1권·정가 12,000원**을 확인하세요. 이 버튼은 **파일만 만들며 서점에 주문을 보내지 않습니다.**

**버튼이 비활성화되어 있나요?** 창의 **저장 전에 확인해 주세요**에 이유가 나옵니다. 구입 선택 책이 없거나, 가격이 비었거나, **확인 필요** 표시가 남았거나, 예산을 넘으면 먼저 고쳐야 합니다. 책 제목을 눌러 내용을 수정한 뒤 다시 열어 보세요.

## 미션 6. 작업 자료도 백업하기

1. 왼쪽 아래 **학교 설정 · 백업**을 누릅니다.
2. **자료 백업과 복원 → 백업 파일 저장**을 누릅니다.
3. 내려받은 `.json` 파일을 확인하고 안전한 곳에 보관합니다.

**성공 신호:** 발주서 `.xlsx`와 별도로 백업 `.json`이 생깁니다. 발주서는 제출용 표이고, 백업은 **구입 목록·소장목록·추천 원본·학교 양식 등 작업 자료를 되살리는 파일**입니다. 인증키는 백업에 들어가지 않습니다.

**축하합니다.** 책을 담고 → 구입을 고르고 → 예산을 보고 → 발주서를 저장하는 기본 흐름을 끝냈습니다. `연습용 도서 구입`은 연습 자료로 남아 있으니, 실제 업무에는 **새 목록 만들기**로 실전 목록을 따로 만드세요.

## 실제 업무 1. 추천 파일이 있다면

학생·교사·기관에서 받은 추천도서 파일은 왼쪽 **파일 가져오기 → 추천도서 목록**으로 넣습니다.

1. **가져올 파일 선택**에서 여러 파일을 함께 고릅니다. 각 파일 이름을 눌러 미리보기를 바꿔 가며 **책 제목·저자·ISBN·정가**가 올바른 열에 들어갔는지 봅니다.
2. 열이 엇갈리면 **열 연결 확인 → 열 연결 적용**으로 고칩니다. 이미 미리보기에서 직접 고친 값과 제외한 행은 유지됩니다.
3. 낯선 행은 **상세 → 원문 보기**로 비교하고, 필요 없는 행은 **×**로 제외합니다.
4. **같은 책 합치기**를 확인하고 **○건 가져오기**를 누릅니다. 여러 출처의 같은 책은 한 종으로 묶이며 **구입 수량은 자동으로 늘지 않습니다.**
5. 왼쪽 **등록 자료 → 추천도서 목록**에서 저장된 책을 출처별로 확인합니다. 원문까지 보려면 **구입 목록으로 돌아가기**를 누르고 도서 목록에서 책 제목을 눌러 **추천 출처와 원문**을 펼칩니다.

**파일이 없거나 열이 복잡한가요?** [그림으로 보는 안내](visual-guide.html)에서 전체 흐름을 먼저 보고, [상세 설명서의 파일 가져오기](user-guide.html#8-추천도서-파일-가져오기)에서 형식별 방법을 찾아보세요. 표의 **일괄 작업**은 여러 권의 서지 확인·구입 선택·보류·삭제에 씁니다. **작업** 체크는 발주 여부를 뜻하지 않습니다.

## 실제 업무 2. 학교 소장목록을 비교하려면

1. 왼쪽 **파일 가져오기 → 학교 소장목록**을 고릅니다.
2. 학교의 **전체 소장목록 파일 1개**를 선택해 미리보기를 확인하고 **○건 가져오기**를 누릅니다.
3. 왼쪽 **등록 자료 → 학교 소장목록**에서 제목·저자·ISBN으로 저장된 자료를 검색합니다.
4. 구입 목록으로 돌아가 책의 **학교 소장** 표시와 **소장 중복** 필터를 확인합니다.

**주의:** 학교 소장목록을 다시 가져오면 **이전에 등록한 소장목록 전체를 교체**합니다. 연습용 파일을 실제 학교 자료 위에 올리지 마세요. **소장 중복**이 보여도 구입 체크는 자동으로 꺼지지 않습니다. 판본과 학교 기준을 확인해 직접 결정합니다.

## 실제 업무 3. 여러 책을 목록에서 빼려면

1. 도서 표에서 뺄 책의 **작업** 체크를 켭니다. 지금 보이는 페이지를 고르려면 **일괄 작업 → 현재 페이지 선택**, 검색·필터 결과를 모두 고르려면 **검색·필터 결과 전체 선택**을 누릅니다. **구입** 체크는 발주 여부를 정하므로 건드릴 필요가 없습니다.
2. **일괄 작업 → 선택한 책 삭제**를 누릅니다. 확인 창의 **N종**이 실제로 뺄 책 수와 같은지 보고 삭제를 확정합니다.
3. 잘못 지웠다면 바로 **일괄 작업 → 되돌리기**를 누릅니다. 모든 책을 지워 목록이 비어도 되돌리기를 누를 수 있습니다.

삭제한 책은 **현재 구입 목록**과 그 목록의 **추천도서 목록**에서 함께 사라집니다. 등록한 **학교 소장목록**은 그대로입니다. 다음 구입 때 다시 살펴볼 책은 삭제 대신 **보류**하세요.

## 막히면 여기부터 확인하세요

| 보이는 상황 | 바로 해 볼 일 |
|---|---|
| 왼쪽 메뉴가 안 보여요 | 창 왼쪽 위 **☰ 메뉴 열기**를 누르거나 창을 넓힙니다. |
| 글자가 작거나 행이 적게 보여요 | 왼쪽 아래 **글자 크기 A+ / A−**, **간결하게**, 창 최대화를 사용합니다. |
| 책이 사라진 것 같아요 | 도서 목록의 검색어를 지우고 **전체** 필터를 누릅니다. **보류** 탭도 확인합니다. |
| 여러 책을 잘못 삭제했어요 | 바로 **일괄 작업 → 되돌리기**를 누릅니다. 모든 책이 사라진 빈 목록에서도 이 버튼을 사용할 수 있습니다. |
| 발주서 저장을 누를 수 없어요 | **저장 전에 확인해 주세요**의 이유를 읽고, 정가·확인 필요·예산·구입 체크를 확인합니다. |
| ISBN 조회가 안 돼요 | 번호와 판본을 확인합니다. ISBN이 없어도 **직접 추가**할 수 있습니다. |
| 저장한 파일을 못 찾겠어요 | 브라우저의 다운로드 목록이나 Windows **다운로드** 폴더를 확인합니다. |

더 자세한 화면별 설명은 [상세 사용설명서](user-guide.html), 그림과 예산 연습은 [그림 안내](visual-guide.html), 학교 Excel 양식은 [학교 양식 안내](school-templates.html)에 있습니다. 외부 서지 조회와 파일 다운로드를 제외한 설명서 글·그림은 인터넷 없이 읽을 수 있습니다.
