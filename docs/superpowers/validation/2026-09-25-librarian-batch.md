## 실제 브라우저 검증

- ISBN 없는 200권을 페이지에 걸쳐 일괄 확인 완료한 뒤 되돌렸다. 각 단계에서 구입 선택 100권·보류 100권이 유지됐다.
- 서로 다른 열 제목을 쓰는 CSV 두 파일의 4행을 함께 가져왔다. 신규 3종·중복 1행 병합 결과를 확인했고, 합친 책의 추천 출처 2개와 구입 수량 1권이 보존됐다.
- 실제 내려받은 XLSX의 도서 103행을 검사했다. ISBN은 모두 빈칸으로 유지됐고, 합친 책의 두 추천 출처가 함께 담겼다.

## 처리 규모와 적용 범위

ISBN 없이 제목·저자·출판사·가격을 갖춘 합성 CSV 50,000행은 로컬 파서에서 4.85초에 읽혔으며 모두 준비 상태로 판정됐다. 서버 테스트는 한 번에 허용하는 최대 20,000행의 통합 처리도 검증했다. 50,000행 측정은 파싱 시간이며, 한 번의 일괄 저장 제한은 20,000행이다.

별도 외부 전처리나 ISBN 조회는 필수가 아니다. 원본 파일을 앱에서 읽고 필요한 열 연결과 예외 행만 확인한다. ISBN 누락만으로 검토를 요구하지 않지만, 불완전하거나 모호한 서지, 잘못된 ISBN, 가격 누락, OCR·수식 등 확인 사유는 검토 대상으로 유지한다.

위 시간과 처리 결과는 로컬 합성자료 및 실행 검증의 관측값이다. 학교별 자료 품질과 선정·심의 절차에 따른 전체 업무 완료 시간을 보장하지 않는다.

## 공개 배포 전 재검증

- 사용자 요청에 따라 2.2.0 정식 공개 배포와 기존 설치형의 자동 업데이트를 준비했다.
- 백엔드 전체 881개 테스트가 204.10초에 다시 통과했다.
- 프런트엔드 전체 176개 테스트가 97.18초에 통과했고 타입 검사·린트·빌드도 통과했다. 병렬 실행 부하로 발생한 화면 테스트 시간 초과를 줄이도록 테스트 작업자를 1개로 고정하고, 200행 기능 검사의 제한 시간을 15초로 조정했다. 제품의 응답 시간이나 실행 방식을 바꾸는 설정은 아니다.
- 업데이트·데스크톱 관련 59개 테스트와 실제 NSIS 설치기 통합 검사를 통과했다. 통합 검사는 격리된 임시 설치 경로에서 잘못된 PID, 앱·업데이트 잠금, 활성 자료 잠금, 부모 프로세스 종료 대기, 파일 교체, 자료 보존, 추출 실패 시 기존 프로그램 보존을 확인했다.
- 자동 설치 대상은 기본 위치의 2.0.2 이상 설치형이며 자동 업데이트 설정이 켜져 있어야 한다. 무설치판과 1.x는 자동 설치 대상이 아니다.
