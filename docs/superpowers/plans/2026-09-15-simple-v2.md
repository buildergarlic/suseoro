# 수서로 2.0 구현 계획

1. 기존 요구사항/파서/API/업무단계를 분석하고 개인 PC 사용으로 다시 정리한다. 기존 작업 폴더의 추적된 수정사항을 새 작업 폴더에 보존한다.
2. `simple/store.py`, `simple/app.py`: 독립 SQLite 목록·도서·소장자료·설정, 선택/보류/수정/삭제취소, 예산 집계, API 경계, 자동저장·백업·복원. 테스트는 임시 데이터폴더에서 구현 전 실패를 확인한다.
3. `simple/documents.py`, `simple/exports.py`: 기존 형식 파서를 재사용해 추천목록 미리보기 및 표준화, 양식 출력과 정확한 합계. 형식별 작은 실제 파일로 회귀 확인한다.
4. `simple/bibliography.py`: 공식 문서에 근거한 무료 API 어댑터, ISBN 일치 검증, 오류/제한/가격미확인 처리. 네트워크 경계는 주입해 단위 테스트하고 실제 공개 조회도 확인한다.
5. `frontend/src/simple/`: 한 화면 목록, 예산, 검색/ISBN추가, 가져오기 미리보기, 편집, 보류/선택, 내보내기/설정. 모바일 크기 대응, 키보드 조작, 서버 오류 표시. 기존 App/테스트는 유지하고 main 진입점만 새 화면에 연결한다.
6. `desktop/`, `installer/`, `scripts/build-desktop.ps1`: 사용자 데이터 분리, 로컬 서버 자동시작/종료, pywebview 창, 설치/제거, 업데이트 설치. 기본 OCR은 한국어/영어로 최소 구성한다.
7. 테스트·실제 브라우저 흐름·설치파일 빌드 후 독립 리뷰를 진행한다. 원본 개인자료/키 없이 공개 소스와 CI를 정리한다.
8. GitHub main에 검증된 변경을 반영하고 v2.0.0 릴리스, Windows 설치 파일, 소스 ZIP 및 SHA256을 공개한다. 공개 URL과 사용 시작 방법을 확인한다.
