읽기 편한 화면으로 시작하세요.

기본 글자는 16px입니다. 왼쪽 메뉴 아래 A− / A+ 또는 선택 상자에서 16·18·20·22·24px를 고르고, 간결하게로 행 간격을 조절하세요. 두 설정은 이 PC에 저장되어 다음 실행에도 복원됩니다. 창 크기를 조절하거나 최대화할 수도 있습니다.

왼쪽 메뉴에 목록·예산·작업 버튼을 모으고 오른쪽 도서 표에서 여러 책을 한 번에 살펴보세요. Ctrl+F로 검색하고 책 제목을 누르면 수정 창이 열립니다. 등록 자료에서 학교 소장목록을 검색하고 저장한 추천도서를 출처별로 볼 수 있습니다. 유효한 ISBN에는 알라딘 공개 상품 페이지 우선 표지를 표시하며, 없으면 표지 없음으로 안내합니다. 표지 조회 시 해당 ISBN을 외부 제공기관에 전송합니다. 표지는 상품·판본을 확정하는 정보가 아닙니다.

여러 추천 파일을 함께 가져와 같은 책의 출처와 원문을 보존하고, ISBN 없는 도서도 서지 확인·구입·보류를 일괄 처리한 뒤 되돌릴 수 있습니다. 별도 전처리나 ISBN 조회는 필수가 아닙니다. 파일 통합과 일괄 검토 방법은 상세 설명서에 있습니다. 실제 국립중앙도서관 승인키의 성공 조회 검증은 아직 수행하지 않았습니다.
