# 수서로 2.1.1 상세 사용설명서

**학교도서관 사서를 위한 도서 구입 목록 안내서**

대상 버전: 수서로 2.1.1 · Windows 10/11 64비트

2.1.1은 공개 버전 2.0.3 이후의 화면·글자 크기·표지·추천 파일·ISBN 조회 개선을 모은 버전입니다. 2.1.0은 로컬 검토만 진행했으며 공개하지 않았습니다.

수서로는 추천받은 책을 한곳에 모으고, 필요한 책을 선택하고, 예산에 맞춘 발주서를 만드는 도구입니다. 회원가입이나 별도 서버 준비 없이 내 PC에서 사용합니다.

처음이라면 [그림으로 보는 쉬운 안내](visual-guide.html)를 먼저 보세요. 짧은 안내는 [이것만 알면 됩니다](quick-start.md)에 있습니다. 이 설명서는 실제 화면의 버튼 이름을 **굵게** 표시합니다.

**프로그램 안에서 보기:** 왼쪽 아래 **사용설명서**를 누릅니다. **그림 안내**, **상세 설명서**, **간단한 사용법** 중 필요한 내용을 고르세요. **닫기**를 누르거나 `Esc`를 누르면 작업하던 목록으로 돌아옵니다. 설명서와 예산 연습은 설치 파일에 들어 있어 인터넷 없이도 이용할 수 있습니다. 이 기능은 2.0.1부터 제공하며, 2.0.0 사용자는 **학교 설정 · 백업 → 업데이트 확인 → 업데이트 설치**로 업데이트하세요.

> **설명서의 학교명·사람·책 제목·가격·구입 사례는 모두 가상이며 연습용입니다.** 실제 업무에서는 학교의 수서 기준, 실물 도서 정보와 확인한 정가를 사용하세요.

## 1. 수서로로 하는 일

**목적:** 책을 고르는 업무의 전체 흐름을 이해합니다.

추천 목록은 **검토할 책을 모아 둔 서랍**, 구입 체크는 **이번에 주문할 장바구니**, 발주서는 **장바구니 내용을 적은 제출용 표**라고 생각하면 쉽습니다.

| 순서 | 사서 선생님이 하는 일 | 수서로가 돕는 일 |
|---|---|---|
| ① 모으기 | 학생·교사의 희망도서와 기관 추천을 수집 | ISBN 조회, 파일 읽기, 후보 목록 저장 |
| ② 살피기 | 판본·정가·학교 적합성·소장 여부 확인 | 원문 확인, 소장·중복 표시, 정보 수정 |
| ③ 고르기 | 필요한 책과 수량 결정 | 구입 선택·보류, 할인금액·잔액 계산 |
| ④ 정리하기 | 학교 기준에 맞춰 최종 점검 | 선택한 도서의 Excel·CSV·인쇄용 파일 저장 |
| ⑤ 보관하기 | 제출 파일과 작업 자료 보관 | 자동 저장, 백업·복원 |

**완료 상태:** “후보를 모두 모아 두고, 체크한 책만 이번 발주서로 보낸다”는 흐름을 이해하면 됩니다.

**기억할 점:** 수서로는 책을 자동 선정하거나 학생의 선호를 추정해 예산을 배분하지 않습니다. 서점으로 주문을 보내거나 학교의 결재를 대신 처리하지도 않습니다. 사서의 판단과 학교의 업무 절차에 필요한 목록을 만듭니다.

## 2. 설치하고 처음 실행하기

**목적:** 자신의 PC에서 수서로를 실행합니다.

### 설치형으로 시작

1. [수서로 공개 배포 페이지](https://github.com/buildergarlic/suseoro/releases/latest)를 엽니다.
2. 해당 릴리스의 **Suseoro-Setup-버전.exe**를 내려받습니다. 전달받은 로컬 검토 파일은 공개 배포물과 구분해서 사용합니다.
3. 내려받은 설치 파일을 실행하고 설치 창의 안내를 따릅니다.
4. 설치가 끝나면 바탕화면 또는 시작 메뉴에서 **수서로**를 엽니다.
5. 왼쪽에 **내 구입 목록**, 오른쪽에 예산과 도서 목록이 나타나는지 확인합니다.

### 설치 없이 시작

1. 같은 배포 페이지에서 **Suseoro-Portable-버전.zip**을 내려받습니다.
2. 압축을 모두 풉니다. 압축 파일 안에서 실행 파일만 여는 방식은 피하세요.
3. 풀린 폴더의 `Suseoro.exe`를 실행합니다.

**완료 상태:** 로그인 화면 없이 구입 목록을 볼 수 있습니다. 처음 제공되는 목록을 그대로 쓰거나 새 목록을 만들면 됩니다.

**기억할 점**

- Windows 10/11 64비트용입니다. 배포 파일에 Python과 한국어·영어 PDF 문자 인식 도구가 포함되어 있어 별도로 준비할 필요가 없습니다.
- 화면이 열리지 않고 WebView2 관련 안내가 나오면 [Microsoft 공식 WebView2 안내](https://developer.microsoft.com/microsoft-edge/webview2/)를 확인하거나 시작 메뉴의 **수서로 (브라우저)**를 이용하세요. 학교 PC의 프로그램 설치 정책은 담당자에게 확인합니다.
- 설치 파일에는 아직 코드 서명 인증서가 적용되지 않았습니다. Windows에서 실행 확인 안내가 나오면 내려받은 곳과 파일명이 위 공식 배포 페이지와 일치하는지 확인하세요.
- 설치형과 무설치형은 **같은 Windows 사용자라면 같은 자료 폴더**를 사용합니다. 무설치 폴더를 하나 더 만든다고 별도의 빈 학교 자료가 생기는 것은 아닙니다.
- 무설치 ZIP을 다른 PC로 복사하는 것만으로 기존 목록이 옮겨지지 않습니다. 자료 이동은 [백업·복원](#14-백업-복원과-다른-pc로-이동)을 사용하세요.

## 3. 학교 이름과 ISBN 조회 설정

**목적:** 화면과 기본 발주서에 학교 이름을 넣고, 필요하면 국내 도서 조회를 보완합니다.

### 학교 이름 저장

1. 왼쪽 아래 **학교 설정 · 백업**을 누릅니다.
2. **우리 학교**의 **학교 이름**에 학교명을 입력합니다.
3. **설정 저장**을 누릅니다.
4. “설정을 저장했습니다.” 안내를 확인하고 **닫기**를 누릅니다.

### 선택 사항: 국립중앙도서관 인증키 등록

1. [국립중앙도서관 인증키 신청·관리](https://www.nl.go.kr/NL/contents/N31101020000.do)를 엽니다. 국립중앙도서관 회원가입 → ISBN 서지정보 API 인증키 신청 → 담당자 승인을 거칩니다.
2. **ISBN 추가** 창의 **국내 도서 조회 설정 → 국립중앙도서관 인증키 등록**을 펼칩니다. 그 안의 **인증키 신청 안내 ↗**로 신청 페이지를 열어도 됩니다.
3. 승인된 키를 **국립중앙도서관 인증키**에 붙여 넣고 **인증키 저장**을 누릅니다. **학교 설정 · 백업**에서도 등록할 수 있습니다.
4. “국립중앙도서관 인증키 등록됨” 안내를 확인한 뒤 알고 있는 책의 ISBN으로 조회합니다. 오류가 나오면 등록한 키와 제공기관 승인 상태를 확인합니다.

인증키 발급 화면과 정책은 제공기관에서 관리하므로, 공식 안내에 따라 이용하세요.

**등록됨은 이 PC에 키가 저장됐다는 뜻입니다. 승인이나 연결 성공을 확인한 결과는 아닙니다.** 실제 승인키를 이용한 성공 조회는 아직 검증하지 않았습니다. 인증 오류와 ISBN 판본 일치 처리는 테스트했으며 실제 결과는 사용자의 승인키로 확인해야 합니다. [공식 ISBN API 안내](https://www.nl.go.kr/NL/contents/N31101030500.do)

**완료 상태:** 첫 화면 상단에 저장한 학교 이름이 표시됩니다. 인증키를 등록하면 다음 ISBN 조회에서 국립중앙도서관에 먼저 요청합니다.

**기억할 점**

- 인증키 없이도 Open Library를 이용한 ISBN 조회가 가능합니다. 국내 도서는 정보가 부족할 수 있습니다.
- 유효한 ISBN과 일치하는 판본을 찾더라도 정가가 없을 수 있습니다. 국립중앙도서관의 **예정가격**도 실제 구입 시점에 확인해야 하는 값입니다.
- 인증키는 화면에 다시 표시하지 않으며 백업에도 넣지 않습니다. 새 PC에서는 다시 등록하세요.
- 등록을 해제하려면 **등록한 인증키 삭제**를 누릅니다. 빈 입력란으로 학교 이름만 저장하면 기존 인증키는 유지됩니다.

## 4. 첫 화면 익히기

**목적:** 필요한 기능을 어디에서 찾는지 익힙니다.

| 화면 위치 | 이름 | 하는 일 |
|---|---|---|
| 왼쪽 | **내 구입 목록** | 연도별 구입 목록을 선택합니다. |
| 왼쪽 | **새 목록 만들기** 또는 목록 옆 **＋** | 새 학기·사업의 목록을 만듭니다. |
| 오른쪽 위 | **목록 · 예산 설정** | 현재 목록의 이름·연도·예산·할인율을 바꿉니다. |
| 오른쪽 위 | **글자 크기 / 간결하게** | 글자와 도서 행 간격을 조절합니다. |
| 화면 위 카드 | **전체 예산** | 현재 목록의 예산입니다. |
| 화면 위 카드 | **구입 선택 금액** | 체크한 도서의 할인 후 금액입니다. |
| 화면 위 카드 | **남은 예산** / **예산 초과 금액** | 예산과 선택 금액의 차이입니다. |
| 목록 위 | **ISBN 추가 / 파일 가져오기 / 발주서 저장** | 모으기와 출력의 시작 버튼입니다. |
| 목록 위 탭 | **전체 / 구입 선택 / 보류 / 확인 필요** | 보고 싶은 후보만 표시합니다. |
| 목록 위 검색 | **도서 검색** | 책 제목·저자·ISBN 등을 입력해 찾습니다. |
| 각 도서 행 | **구입** 체크 / 책 제목 / **수정** | 선택 상태를 바꾸거나 책 정보를 수정합니다. |
| 책 제목 왼쪽 | 표지 썸네일 / **표지 없음** | ISBN에 대해 제공기관이 보내 준 표지를 보여 줍니다. |
| 책 정보 아래 | **알라딘 ↗ / 국립중앙도서관 ↗ / 참고 링크 ↗** | ISBN 검색 또는 저장한 참고 페이지를 엽니다. |
| 목록 아래 | **＋ 직접 추가** | ISBN 조회 없이 책을 입력합니다. |
| 왼쪽 아래 | **개발자 후원** | 개발자 소개와 자발적 후원 안내를 엽니다. |
| 왼쪽 아래 | **학교 설정 · 백업** | 학교명·인증키·백업·업데이트·종료 기능입니다. |
| 왼쪽 아래 | **사용설명서** | 프로그램 안에서 그림 안내·상세 설명서·간단한 사용법을 엽니다. |

**보는 순서:** 왼쪽에서 목록을 선택하고 → 위에서 예산을 보고 → 아래에서 책을 고릅니다.

**완료 상태:** 작업 중인 목록 이름과 예산이 맞는지 확인할 수 있습니다.

**기억할 점:** 탭과 검색은 **보이는 행만 바꾸는 기능**입니다. 검색 결과에 보이지 않는 책도 구입에 체크되어 있으면 발주서에 포함됩니다. 발주 전 **구입 선택** 탭에서 검색어를 지우고 전체 선택 목록을 확인하세요.

### 글자 크기·행 간격·빠른 검색

- 기본 글자 크기는 **18px**입니다. 오른쪽 위 **글자 크기**의 **A− / A+**를 누르거나 선택 상자에서 **16·18·20·22·24px**를 고르세요. 앱 화면의 글자 크기가 바뀝니다.
- **간결하게**를 켜면 도서 행의 여백이 줄어 한 화면에서 더 많은 책을 볼 수 있습니다. 다시 누르면 넉넉한 간격으로 돌아옵니다.
- 이 두 설정은 이 PC의 앱 자료에 저장되어 프로그램을 종료한 뒤 다시 열어도 복원됩니다. 이미 선택해 둔 16·18·20px 크기는 유지하며, 새로 시작하는 경우에 18px를 사용합니다. 다른 PC로 옮기는 학교 자료 백업에는 화면 설정이 포함되지 않습니다.
- 창 가장자리를 끌어 넓히거나 제목 표시줄의 **최대화**를 누르면 더 넓게 볼 수 있습니다. 큰 글자나 좁은 창에서 열이 다 보이지 않으면 도서 표 안의 가로 스크롤로 정가·수량·수정 열을 확인하세요. 글자 설정은 발주서의 가격·수량을 바꾸지 않습니다.
- 별도 창이 열려 있지 않은 목록 화면에서 `Ctrl+F`를 누르면 **도서 검색**으로 이동합니다. 제목·저자·ISBN을 입력하고, **검색어 지우기**로 전체 목록을 다시 봅니다.
- 책 제목이나 **수정**을 누르면 오른쪽 편집 영역이 열립니다. 고친 값은 **저장**을 눌러야 반영됩니다.

### 책 표지 보기

유효한 ISBN이 있으면 책 제목 왼쪽에 Open Library 또는 Google Books가 제공하는 표지 썸네일을 표시합니다. ISBN이 없거나 잘못되었거나, 제공되는 표지가 없거나 연결에 실패하면 **표지 없음**이 보입니다. 표지 유무는 목록 저장·도서 선택·발주서 작성에 영향을 주지 않습니다.

표지를 조회할 때 해당 ISBN을 외부 제공기관에 전송합니다. 표지 조회에는 인터넷이 필요하며 학교명·요청자·메모·추천 문서 전체를 보내지 않습니다. **표지는 책을 알아보기 위한 참고 그림이며 상품·판본·정가가 맞다는 확정 표시가 아닙니다.** 실제 ISBN과 서지정보를 함께 확인하세요.

### 개발자 후원

왼쪽 아래 **개발자 후원**을 누르면 개발자 소개와 후원 안내를 볼 수 있습니다. **GitHub에서 후원하기 ↗**를 누르면 브라우저에서 [빌더갈릭의 GitHub Sponsors](https://github.com/sponsors/buildergarlic)가 열립니다. 금액과 후원 방식은 후원 페이지에서 직접 선택하세요. 후원은 선택 사항이며 모든 기능은 후원 없이도 사용할 수 있습니다. **목록으로 돌아가기** 또는 `Esc`로 안내를 닫으면 작업 중인 목록으로 돌아옵니다.

## 5. 구입 목록과 예산 설정

**목적:** 이번 구입 업무에 사용할 목록과 예산을 정합니다.

### 새 목록 만들기

1. 왼쪽의 **새 목록 만들기**를 누릅니다.
2. **목록 이름**을 입력합니다. 예: `2026년 2학기 도서 구입 — 연습`.
3. **연도**, **예산 (원)**, **할인율 (%)**을 입력합니다.
4. **저장**을 누릅니다.

기본 예산은 **15,000,000원**, 기본 할인율은 **0%**입니다. 현재 목록을 바꾸려면 오른쪽 위 **목록 · 예산 설정**을 누릅니다.

### 금액이 계산되는 방법

1. 한 권의 정가에 목록 할인율을 적용합니다.
2. 할인 후 한 권의 금액을 **원 단위 반올림**합니다.
3. 그 금액에 수량을 곱합니다.
4. 구입에 체크한 도서의 금액을 합칩니다.

| 연습 값 | 계산 | 결과 |
|---|---|---:|
| 정가 15,000원, 할인 10%, 수량 2권 | 15,000 × 0.9 × 2 | 27,000원 |
| 정가 12,345원, 할인 10%, 수량 3권 | 한 권 11,110.5원을 11,111원으로 반올림한 뒤 × 3 | 33,333원 |

위 두 도서 행을 모두 선택했다면 **2종·5권**, 선택 금액은 **60,333원**입니다. 예산이 15,000,000원이면 남은 예산은 **14,939,667원**입니다.

**완료 상태:** 카드에 입력한 예산과 할인율이 보이고, 책을 선택하거나 수량을 바꾸면 금액이 다시 계산됩니다.

**기억할 점**

- 할인율은 목록 전체에 적용하며 소수점 둘째 자리까지 입력할 수 있습니다. 예시의 10%는 연습값입니다. 실제로 적용할 할인율은 학교의 구입 조건에 맞춥니다.
- **정가 칸에는 정가**를 입력합니다. 할인된 단가를 정가 칸에 넣고 할인율까지 설정하면 할인이 두 번 적용됩니다.
- 가격이 빈 도서는 선택 수량에는 포함되지만 선택 금액에서 빠집니다. “가격 미확인 ○종은 선택 금액에 포함되지 않았어요.” 안내를 확인하세요.
- 예산은 **목록별로 독립 계산**합니다. 여러 목록의 예산과 지출을 학교 연간 총예산으로 자동 합산하지 않습니다. 연간 1,500만 원을 두 학기로 나누면 각 목록에 배정한 금액의 합계를 별도로 관리하세요.

## 6. ISBN으로 책 추가하기

**목적:** 책의 ISBN만으로 제목·저자·출판사 등 확인 가능한 정보를 불러옵니다.

ISBN은 책 뒷면 바코드 주변에서 볼 수 있는 도서 식별번호입니다. 같은 제목이라도 개정판·다른 판형·전자책이면 ISBN이 다를 수 있습니다. 구입하려는 **해당 판본**의 번호를 사용하세요.

### 클릭 순서

1. 책을 담을 목록을 선택합니다.
2. **ISBN 추가**를 누릅니다.
3. ISBN을 한 줄에 하나씩 붙여 넣습니다. 쉼표로 구분해도 됩니다. 한 번에 최대 **100개**를 조회합니다.
4. **조회하고 추가**를 누릅니다.
5. 각 ISBN의 조회 결과를 확인합니다. **일치하는 책을 찾으면 그 즉시 목록에 저장됩니다.** 별도의 책별 저장 버튼을 누르는 순서가 아닙니다.
6. 조회가 끝나면 **닫기**를 누릅니다.
7. 추가된 책의 제목 또는 **수정**을 눌러 정가·수량·판본을 확인하고 필요한 정보를 고친 뒤 **저장**합니다.

**완료 상태:** 목록에 새 책이 나타납니다. 기본적으로 구입 선택 상태이며, 가격이 없는 도서는 **가격 미확인**으로 보입니다.

### 결과에 따른 다음 행동

| 조회 결과 | 다음에 할 일 |
|---|---|
| 목록에 추가했습니다 | 책 제목·저자·출판사·ISBN을 보고 정가·수량도 확인합니다. |
| 추가됨 · 가격은 직접 확인해 주세요 | 책의 **수정**을 열어 확인한 정가를 입력합니다. |
| 일치하는 책을 찾지 못했습니다 | 번호와 판본을 확인한 뒤 다시 조회하거나 **ISBN 없이 직접 추가**를 사용합니다. |
| ISBN 형식이나 확인 안내 | 잘못 옮긴 숫자, 불필요한 문구, 책과 다른 바코드 번호가 없는지 확인합니다. |
| 연결 오류 | 인터넷 연결을 확인하고 잠시 뒤 다시 시도합니다. 추가에 성공한 결과도 함께 확인합니다. |

**기억할 점**

- ISBN 10자리와 13자리를 사용합니다. 번호 안의 하이픈·공백은 정리하지만 **서로 다른 ISBN은 줄바꿈이나 쉼표로 구분**하세요.
- 조회 결과 창을 닫아도 성공해서 추가한 책은 목록에 남습니다. 실패한 항목이 있다고 성공한 항목까지 취소되는 것은 아닙니다.
- 같은 조회 창에서는 이미 추가한 동일 번호를 다시 추가하지 않도록 안내합니다. 창을 닫았다 다시 조회하거나 다른 파일로 가져온 중복까지 자동 제거하는 기능은 아닙니다.
- 무료 API의 정보 범위와 제공 상태에 따라 결과가 달라집니다. 찾지 못했다는 결과는 “그 책이 존재하지 않는다”는 뜻이 아닙니다.
- **예정가격** 등 확인할 안내가 있으면 실제 정보를 검토한 뒤 [확인 필요 표시](#10-구입-선택보류확인-필요-관리)를 해제합니다. 가격을 항상 정확하게 자동 완성한다고 가정하지 마세요.

### 알라딘·국립중앙도서관에서 판본 확인

유효한 ISBN이 있는 책에는 **알라딘 ↗**, **국립중앙도서관 ↗**가 나타납니다. 책을 수정할 때와 목록에서 이 링크를 열어 제목·저자·출판사·ISBN·정가를 비교하세요. ISBN-10은 같은 판본의 ISBN-13으로 정리해 검색합니다. ISBN이 없거나 잘못되었으면 먼저 번호를 확인하세요.

알라딘 링크는 **국내도서 ISBN 검색**, 국립중앙도서관 링크는 **소장자료 ISBN 검색**입니다. 확정된 상품 상세 링크나 주문 버튼이 아니며, 품절 도서·외국 도서·출판예정 도서 등은 결과가 없을 수 있습니다. **참고 링크 ↗**는 따로 저장한 확인 출처를 엽니다.

알라딘은 신규 API 인증키 발급을 **2026년 9월 4일** 종료했고, 기존 API도 **10월 30일** 종료할 예정입니다. 수서로는 신규 알라딘 API를 연결하지 않으며, 외부 ISBN 검색 링크만 제공합니다. [공식 종료 공지](https://blog.aladin.co.kr/openapi/17486624)

## 7. 직접 추가하고 책 정보 수정하기

**목적:** ISBN이 없는 자료를 담거나, 불러온 도서 정보를 실제 구입 조건에 맞게 고칩니다.

### 직접 추가

1. 목록 아래의 **＋ 직접 추가**를 누릅니다. 빈 목록에서는 **책 정보를 직접 입력할게요**를 눌러도 됩니다.
2. **책 제목**과 알고 있는 정보를 입력합니다.
3. 정가가 아직 확인되지 않았다면 **정가 (원)**을 빈칸으로 둡니다.
4. 수량을 입력하고 **구입할 책으로 선택** 여부를 정합니다.
5. 나중에 더 검토할 내용이 있으면 **확인 필요 표시**를 켭니다.
6. **저장**을 누릅니다.

### 기존 책 수정

1. 책 제목 또는 그 행의 **수정**을 누르면 목록 오른쪽에 **책 정보 수정** 영역이 열립니다.
2. 고칠 값을 입력합니다. 필요한 경우 **알라딘 ↗ / 국립중앙도서관 ↗**를 열어 판본·정가를 확인합니다.
3. **저장**을 누릅니다. **취소**, 닫기 또는 `Esc`로 닫으면 저장하지 않은 수정은 반영되지 않습니다.

| 입력란 | 활용 예와 의미 |
|---|---|
| 책 제목·저자·출판사·ISBN | 구입할 판본을 확인하는 기본 정보 |
| 정가 (원) | 확인한 한 권의 정가. 빈칸은 미확인, 0원과 다릅니다. |
| 수량 | 이번에 구입할 권수. 1권 이상의 정수를 입력합니다. |
| 분류 | `문학`, `과학`, `813.8` 등 학교에서 알아보기 쉬운 표기 |
| 요청자 | `3학년 학생 요청`, `과학교사 요청` 등 선정 배경 |
| 대상 | `초등 3–4학년`, `중학교 전 학년` 등 |
| 우선순위 | 높음·보통·낮음. 판단을 돕는 기록입니다. |
| 추천 출처 | 어느 기관·교사·학생 추천인지 기록 |
| 발행일·참고 링크 | 판본이나 확인 출처 참고. 링크는 `https://` 주소를 사용합니다. |
| 메모 | 선정 이유, 수업 연계, 복본 필요성, 다시 확인할 내용 |

### ISBN으로 빈칸만 보완

수정 창에 ISBN을 입력하고 **ISBN으로 빈 정보 채우기**를 누르면, 입력한 제목·가격 등은 유지하며 빈 정보를 보완합니다. 결과를 검토한 뒤 **저장**해야 수정 내용이 반영됩니다. 이미 잘못 입력된 값은 빈칸이 아니므로 직접 고쳐야 합니다.

### 삭제와 삭제 취소

1. 수정 창에서 **이 책 삭제**를 누릅니다.
2. 삭제가 잘못되었다면 화면 위에 남아 있는 삭제 알림에서 **삭제 취소**를 누릅니다.
3. 책이 다시 나타났는지 확인합니다.

**완료 상태:** 목록의 정보·수량·금액이 수정한 값으로 보입니다. 삭제한 책은 현재 목록에서 사라집니다.

**기억할 점:** 아직 살지 결정하지 못한 책은 삭제보다 **보류**가 편합니다. 삭제 취소는 화면의 최근 삭제 알림을 통해 사용하며, 알림을 닫거나 화면을 다시 열면 그 버튼을 이용할 수 없습니다. 다른 책을 삭제하면 최근 삭제 대상도 바뀝니다. 전체 삭제 이력을 자유롭게 복원하는 휴지통 화면은 없습니다.

## 8. 추천도서 파일 가져오기

**목적:** 여러 기관의 서로 다른 추천 목록을 일정한 도서 행으로 정리합니다.

### 준비할 파일

파일 선택 화면은 `.xlsx`, `.xls`, `.csv`, `.tsv`, `.txt`, `.pdf`, `.hwp`, `.hwpx`, `.docx`를 받습니다. **파일당 50 MB 이하**로 준비하세요. ODS나 XLSB 파일은 현재 화면에서 직접 고르기보다 Excel 등의 프로그램에서 `.xlsx`로 저장해 사용하세요.

| 원본 종류 | 가져오기 전 확인하면 좋은 점 |
|---|---|
| Excel·CSV·TSV | 한 행에 한 책, 제목·저자·ISBN·정가·수량을 각각 다른 열로 정리하면 쉽습니다. 합계·소제목 행은 도서와 구분합니다. |
| 텍스트 PDF | 표와 열이 잘 구분되는 원본을 사용합니다. 여러 단이나 페이지에 걸친 도서는 원문과 비교합니다. |
| 스캔 PDF | 한국어·영어 문자 인식을 시도합니다. 기울거나 흐릿한 이미지의 숫자·가격·ISBN을 특히 확인합니다. |
| HWP·HWPX·DOCX | 표 형태가 유리합니다. 암호화 문서나 복잡한 편집, 일부 구형 HWP는 제대로 읽히지 않을 수 있습니다. |
| TXT | 책별 구분이 분명한 목록을 사용합니다. 긴 소개글은 제목·가격·저자가 정확하게 나뉘지 않을 수 있습니다. |

2.1에서는 위쪽 빈 행과 안내문, 병합된 여러 줄 머리글, 페이지·시트 안의 반복 머리글과 합계행을 더 잘 구분합니다. `정가(원)`, `신청수량(권)`처럼 단위가 붙은 열 이름과 ISBN10/ISBN13 열도 함께 살핍니다. 여러 시트의 열 이름이 달라도 원래 시트·행 위치를 보존하며 처리합니다.

미리보기에서 건너뛴 행과 인식 경고도 확인하세요. 수식 가격은 임의 계산해 정가로 확정하지 않으며, 유효한 ISBN이 둘 이상인데 서로 다르면 직접 판본을 확인해야 합니다. 개선된 양식 사례를 확인한 기능이므로 모든 기관 문서를 정확히 읽는다고 가정하지 마세요.

### 클릭 순서: 열 연결을 먼저, 개별 수정은 나중에

1. 구입 후보를 담을 목록을 선택하고 **파일 가져오기**를 누릅니다.
2. 위쪽에서 **추천도서 목록**을 선택합니다.
3. **가져올 파일 선택**을 눌러 파일을 엽니다.
4. 미리보기의 건수와 **확인할 점**을 읽습니다. 이 단계에서는 아직 구입 목록에 추가되지 않았습니다.
5. 제목·저자·ISBN·정가·수량이 올바른 칸에 들어갔는지 봅니다.
6. 열이 잘못 연결되었다면 **열 연결 확인 · 제목이나 가격이 다른 열에 있나요?**를 펼칩니다. 파일의 열 이름이 제공되는 경우에 사용할 수 있습니다.
7. 수서로의 각 항목에 맞는 원본 열을 선택하고 **열 연결 적용**을 누릅니다. 예를 들어 수서로의 **책 제목**에 원본의 `서명`, **정가**에 원본의 `도서정가` 열을 연결합니다.
8. 연결이 맞아진 뒤 책 제목·저자·ISBN·정가·수량을 미리보기에서 고칩니다. 더 많은 항목은 행의 **상세**를 누릅니다.
9. 합계행·안내 문구·이번에 가져오지 않을 행은 오른쪽 **×**로 제외합니다.
10. 필요한 경우 **ISBN으로 빈 정보 채우기**를 이용하고 원문과 결과를 검토합니다.
11. 최종 건수와 자료 종류가 맞으면 **○건 가져오기**를 누릅니다.

> **열 연결 적용은 원본 파일을 다시 읽습니다.** 미리보기에서 고친 값이나 제외한 행, 조회로 채운 정보를 유지하는 단계가 아닙니다. 열 연결을 먼저 끝낸 뒤 개별 수정과 검토를 진행하세요.

### 원문을 비교하는 방법

1. 확인할 행의 **상세**를 누릅니다.
2. **가져올 때 확인할 점**을 읽습니다.
3. **원문 보기**가 제공되면 펼쳐서 원문과 제목·ISBN·정가를 비교합니다. 제공되지 않는 경우 원본 파일을 직접 열어 비교하세요.
4. 값을 고치고 확인이 끝났다면 **확인 필요 표시**를 해제합니다.
5. **미리보기로 돌아가기**를 누릅니다. 이 창의 수정은 마지막 **○건 가져오기**를 눌러야 목록에 반영됩니다.

### ISBN으로 빈 정보 채우기: 한 번에 최대 50권

- ISBN이 있으며 제목·저자·출판사·정가 중 빈 정보가 있는 행을 대상으로 조회합니다.
- 한 번에 앞쪽 대상 행 **최대 50권**을 처리하며 진행 건수를 보여 줍니다.
- **조회 중지**를 누르면 진행 중인 조회가 끝난 뒤 다음 조회를 중지합니다. 이미 채운 결과는 남습니다.
- 기존에 입력한 정보는 유지합니다. 채워진 결과도 직접 확인할 수 있도록 **확인 필요**로 표시합니다.
- 정가를 찾지 못하는 등 빈값이 계속 남으면 다음 실행에서도 같은 행이 대상이 될 수 있습니다. **버튼을 두 번 누른다고 반드시 다음 50권을 처리하는 것은 아닙니다.** 많은 파일은 50권 정도씩 나누어 처리하면 확인하기 쉽습니다.

**완료 상태:** “추천도서 ○건을 가져왔습니다.” 안내와 함께 현재 구입 목록에 도서 행이 나타납니다. 가격 미확인·확인 필요 상태도 후보로 저장할 수 있습니다.

**기억할 점**

- 미리보기의 **준비됨**은 해당 행에 확인 필요 표시가 없다는 뜻입니다. 정확한 판본·정가 확인이나 최종 구입 승인을 대신하지 않습니다.
- 숫자가 잘못 읽혔을 때는 정가·할인가·세트가격·수량이 바뀌지 않았는지 봅니다. “10권 150,000원”을 한 권 정가 150,000원으로 넣지 않도록 확인하세요.
- 미리보기 행의 가격 합계는 **정가 × 수량**입니다. 목록 할인율을 반영한 최종 선택 금액은 가져온 뒤 예산 카드에서 확인합니다.
- 이 단계의 **×**는 원본 파일의 행을 지우지 않습니다. 현재 미리보기에서 제외합니다. 잘못 제외했다면 원본을 다시 읽을 수 있지만, 그때는 다른 미리보기 수정도 다시 해야 합니다.
- 가져오기를 반복하면 같은 책이 다시 추가될 수 있습니다. 가져온 후 **중복 추천** 표시를 검토하세요.

## 9. 학교 소장목록으로 중복 구입 살피기

**목적:** 이미 학교에 있는 책인지 비교해 불필요한 중복 구입을 줄입니다.

### 클릭 순서

1. 학교에서 관리하는 **최신 전체 소장목록** 파일을 준비합니다. 가능하면 ISBN, 제목, 저자가 포함된 표를 사용하세요.
2. 수서로에서 **파일 가져오기**를 누릅니다.
3. **학교 소장목록**을 선택합니다. **추천도서 목록**과 혼동하지 마세요.
4. 파일을 선택하고 열 연결·ISBN·제목·저자와 미리보기 건수를 확인합니다.
5. 창 아래의 “기존 소장목록을 위의 ○건으로 교체합니다.” 안내를 읽습니다.
6. 학교의 전체 자료가 맞으면 **○건 가져오기**를 누릅니다.
7. 구입 후보에서 **학교 소장** 표시를 확인합니다.

**완료 상태:** 소장 자료가 구입 후보로 추가되는 대신, 기존 구입 후보와 비교되어 같은 책에 **학교 소장** 표시가 나타납니다. 소장목록은 이 PC의 여러 구입 목록에서 함께 사용합니다.

**기억할 점**

- 새로 가져온 소장목록은 이전 소장목록에 덧붙이지 않고 **전체를 교체**합니다. 최근 입수한 책만 담긴 파일을 넣으면 기존 소장 도서의 비교 정보가 빠집니다. 여러 파일이라면 전체 목록으로 합친 뒤 가져오세요.
- 유효한 ISBN이 같으면 같은 판본으로 비교합니다. ISBN이 없는 자료는 제목과 저자를 이용한 비교가 가능하지만 정확도가 떨어질 수 있습니다.
- 서로 다른 유효 ISBN의 판본은 제목이 같아도 별도로 판단합니다. 같은 작품의 구판·개정판을 모두 가진 경우는 사서가 추가로 확인하세요.
- **학교 소장**은 안내 표시이며 자동으로 구입 체크를 해제하지 않습니다. 학급용 복본, 훼손 도서 교체 등 추가 구입이 필요하면 사유를 메모하고 선택할 수 있습니다.
- 학교 도서관 시스템과 실시간으로 연결되는 기능이 아닙니다. 비교는 마지막에 가져온 소장목록을 기준으로 합니다.

## 10. 구입 선택·보류·확인 필요 관리

**목적:** 모든 후보를 보관하면서 이번에 살 책만 구분하고, 불확실한 정보를 해결합니다.

### 구입과 보류 바꾸기

1. 도서 행 왼쪽 **구입** 체크를 켜면 이번 구입에 선택됩니다.
2. 체크를 끄면 **보류**가 됩니다. 도서 정보는 남으며 선택 금액과 발주 대상에서 빠집니다.
3. **구입 선택** 또는 **보류** 탭을 눌러 결과를 확인합니다.

### 확인이 끝난 책 정리하기

1. **확인 필요** 탭을 엽니다.
2. 책의 **수정**을 누르고 제목·정가·ISBN과 **가져올 때 확인할 점**을 봅니다.
3. 실물·원본 문서·확인 가능한 서지정보와 대조해 값을 수정합니다.
4. 검토가 끝나면 **확인 필요 표시** 체크를 해제합니다.
5. **저장**을 누릅니다. 제목·정가가 여전히 비어 있으면 계속 확인 필요 탭에 나타날 수 있습니다.

| 표시·탭 | 뜻 | 자동으로 하지 않는 일 |
|---|---|---|
| **구입 선택** | 이번 발주서에 포함하도록 체크한 후보 | 정보의 정확성이나 학교의 승인 확정 |
| **보류** | 이번 발주에서는 제외한 후보 | 후보 삭제 |
| **확인 필요** 탭 | 확인 필요 표시가 있거나, 제목·정가가 빈 도서 | 모든 종류의 오류·중복을 빠짐없이 모으기 |
| **학교 소장** | 가져온 소장목록에 같은 책으로 비교된 자료 | 자동 구입 제외 |
| **중복 추천** | 현재 구입 목록에 같은 ISBN 또는 비교 가능한 제목·저자의 행이 중복 | 여러 행을 한 행으로 합치기 |
| **가격 미확인** | 정가 칸이 비어 있음 | 0원으로 확정 |

**완료 상태:** 선택할 책과 보류할 책이 나뉘고, 선택 금액과 권수가 의도한 값으로 보입니다.

**기억할 점**

- 잘못된 ISBN이나 소장·중복 표시가 있다는 이유만으로 항상 **확인 필요** 탭에 나타나지는 않습니다. 최종 점검은 **구입 선택** 탭에서도 진행하세요.
- 중복은 **현재 목록 안에서** 비교합니다. 다른 학기·사업 목록에 같은 책이 있는지 자동으로 모두 찾아주지는 않습니다.
- 동일 도서가 추천 출처별로 중복되었다면 남길 한 행의 메모·출처에 선정 근거를 정리하고, 다른 행을 보류하거나 삭제하세요. 복본을 구입하려면 수량도 확인합니다.
- 우선순위·분류·요청자·대상은 판단을 돕는 기록입니다. 우선순위를 “높음”으로 바꾸어도 자동 선택·정렬·예산 배분이 실행되지 않습니다.
- 확인을 마치지 못한 후보는 보류 상태로 남겨 두고, 확인한 선택 도서만 발주할 수 있습니다.

## 11. 최종 발주서 저장하기

**목적:** 구입 선택한 책을 학교에서 검토·제출할 파일로 만듭니다.

### 저장 전에 확인할 조건

- [ ] 구입에 체크한 책이 한 종 이상 있습니다.
- [ ] 선택한 책의 제목이 모두 있습니다.
- [ ] 선택한 책의 정가를 모두 확인했습니다.
- [ ] 입력된 ISBN이 올바릅니다. 원래 ISBN이 없는 자료는 빈칸으로 둘 수 있습니다.
- [ ] 선택한 책의 **확인 필요 표시**를 검토 후 해제했습니다.
- [ ] 선택 금액이 현재 목록의 예산을 넘지 않습니다.

가격·제목·확인 필요 상태나 예산 문제는 저장 창에서 안내합니다. 잘못된 ISBN은 **발주서 저장**을 눌렀을 때 오류로 안내될 수 있으므로 함께 점검하세요. 소장·중복 표시는 그 자체만으로 저장을 막지는 않습니다.

### 클릭 순서

1. **구입 선택** 탭을 누르고 검색어를 지웁니다.
2. 구입 도서·수량·학교 소장·중복을 검토합니다.
3. **발주서 저장**을 누릅니다.
4. 창 위의 학교명·목록명·종수·권수·할인율·금액을 확인합니다.
5. 저장 형식을 선택합니다.
6. **발주서 저장**을 누르고 내려받은 파일의 저장 위치를 확인합니다.
7. 파일을 열어 표와 합계가 맞는지 확인한 뒤 학교의 절차에 따라 제출합니다.

| 형식 | 만들어지는 파일 | 활용 방법 |
|---|---|---|
| **Excel** | `.xlsx` | 편집·인쇄할 수 있는 기본 발주서 또는 등록한 학교 양식 |
| **CSV** | `.csv` | 표 데이터를 다른 프로그램에서 처리. 서식과 학교 표지 양식은 포함하지 않습니다. |
| **인쇄용** | `.html` | 브라우저로 열어 인쇄하거나 브라우저의 인쇄 기능에서 PDF로 저장 |

### PDF가 필요할 때

1. **인쇄용**으로 발주서를 저장합니다.
2. 내려받은 `.html` 파일을 Edge·Chrome 등 브라우저에서 엽니다.
3. 브라우저에서 인쇄를 실행합니다. Windows에서는 보통 `Ctrl + P`를 사용합니다.
4. 인쇄 대상에서 **PDF로 저장** 또는 **Microsoft Print to PDF** 등 사용 가능한 PDF 방식을 선택합니다.
5. 미리보기에서 가로 방향, 여백, 페이지 수를 확인하고 저장합니다. 메뉴 이름은 브라우저에 따라 다를 수 있습니다.

**완료 상태:** 선택한 책만 포함된 파일이 PC에 저장되어 열 수 있습니다.

**기억할 점**

- 화면의 검색·필터 결과가 아니라 **현재 목록에서 구입에 체크한 모든 도서**를 출력합니다.
- 수서로가 `.pdf`, `.hwp`, `.hwpx` 발주서를 직접 생성하는 것은 아닙니다. 한글 문서 양식 제출이 필요하면 Excel/CSV 내용을 학교 양식으로 옮겨 최종 서식을 확인하세요.
- CSV를 특정 도서관 시스템에 그대로 올릴 수 있다고 보장하지 않습니다. 업로드 대상이 요구하는 열 순서·필드·ISBN 형식을 확인하세요.
- 저장한 발주서 파일을 Excel에서 수정해도 수서로의 원래 목록이 자동 수정되지는 않습니다. 양쪽 자료가 달라지지 않도록 최종 수정본을 관리하세요.
- **발주서 저장은 파일을 만드는 작업**입니다. 서점으로 실제 주문을 보내지는 않습니다.

## 12. 학교 Excel 양식 사용하기

**목적:** 학교에서 쓰는 열 이름과 서식에 맞춰 발주서를 저장합니다.

### 가장 쉬운 준비 방법

1. 학교 양식을 일반 **`.xlsx`**로 저장합니다.
2. 도서 표는 **한 행에 한 책**이 들어가도록 구성합니다.
3. 표의 열 제목을 첫 100행 안에 한 줄로 둡니다. 다음처럼 명확한 이름이 좋습니다.

   | 번호 | 도서명 | 저자 | 출판사 | ISBN | 정가 | 수량 | 구입단가 | 금액 | 비고 |
   |---|---|---|---|---|---|---|---|---|---|
   |  |  |  |  |  |  |  |  |  |  |

4. 열 제목 바로 아래에 도서 한 권이 들어갈 기본 행을 둡니다. 글꼴·테두리·높이·정렬을 원하는 모양으로 설정합니다.
5. 학교명·문서 제목은 위쪽, 합계·결재·서명란은 도서 행 아래쪽에 둡니다.
6. 실제 구입 목록이 가득한 이전 발주서보다 **도서 데이터 행 한 줄을 준비한 빈 양식**을 사용합니다.

### 수서로에 등록하고 저장

1. **발주서 저장 → Excel**을 선택합니다.
2. **학교 양식 추가 (.xlsx)**를 눌러 양식을 선택합니다.
3. 표시된 경고가 있다면 읽습니다. 가격 열이나 수식 관련 안내가 나올 수 있습니다.
4. **발주서 양식**에 등록한 파일이 선택되었는지 확인합니다.
5. **발주서 저장**을 누르고 결과 파일을 Excel에서 엽니다.
6. 학교명·도서 행·수량·단가·금액·합계·인쇄 범위를 확인합니다.

등록한 양식은 다음 발주에서도 선택할 수 있습니다. 수서로는 원본 양식을 수정하는 대신 별도의 결과 파일을 만듭니다.

### 열 제목을 인식하지 못하면: 치환 표시 사용

치환 표시란 **“여기에 이 정보를 넣어 주세요”라는 자리표**입니다. 예를 들어 `{{title}}`이라고 적은 셀에는 책 제목을 넣습니다. 중괄호 두 쌍과 영문 이름을 그대로 입력하세요.

학교 고유의 열 제목을 유지하고 싶다면, 그 아래 **도서 한 권의 데이터 행**에 다음 표시를 각각 한 셀씩 넣습니다. 치환 표시 행도 첫 100행 안에 두세요.

| 셀에 넣을 표시 | 들어갈 정보 |
|---|---|
| `{{number}}` | 도서 행 번호 |
| `{{title}}` | 책 제목 |
| `{{author}}` | 저자 |
| `{{publisher}}` | 출판사 |
| `{{isbn}}` | ISBN |
| `{{price}}` | 한 권의 정가 |
| `{{quantity}}` | 수량 |
| `{{order_price}}` | 할인 후 한 권의 구입단가 |
| `{{line_total}}` | 구입단가 × 수량 |
| `{{discount_percent}}` | 목록 할인율 숫자 |
| `{{category}}` / `{{requester}}` / `{{audience}}` | 분류 / 요청자 / 대상 |
| `{{priority}}` | 기록한 우선순위 값 (`high`, `normal`, `low`) |
| `{{source}}` / `{{note}}` / `{{published_date}}` | 추천 출처 / 메모 / 발행일 |

도서 표에는 최소한 **도서명 또는 ISBN에 해당하는 열**이 있어야 합니다. 읽기 쉬운 발주서를 위해 제목·정가·수량·구입단가·금액 열도 갖추는 것을 권합니다. **열 이름을 `단가`로 쓰면 수서로는 정가로 인식합니다.** 할인 후 한 권의 가격을 넣을 열에는 **구입단가** 또는 `{{order_price}}`를 사용하세요.

### 학교명·문서 제목·합계 자동 채우기

표 위아래의 셀에는 다음 치환 표시를 사용할 수 있습니다.

| 표시 | 의미 |
|---|---|
| `{{school_name}}` | 학교 설정에서 저장한 학교명 |
| `{{list_name}}` | 현재 구입 목록 이름 |
| `{{year}}` | 목록 연도 |
| `{{book_count}}` | 구입 선택한 도서 행 수, 즉 종수 |
| `{{total_quantity}}` | 구입 선택 수량의 합계, 즉 권수 |
| `{{list_total}}` | 할인 전 정가 × 수량의 합계 |
| `{{order_total}}` | 할인 후 최종 구입 금액 |
| `{{budget}}` | 목록 예산 |
| `{{remaining}}` | 남은 예산 |

예를 들어 표 위의 셀을 `{{school_name}} 도서 구입 발주서`로 만들 수 있습니다. 학교명이 **“햇살초등학교”처럼 고정된 글자**로 적혀 있으면 다른 학교 이름으로 자동 교체되지 않습니다. 다른 학교에서도 쓸 양식이라면 `{{school_name}}`을 사용하거나 출력 후 직접 고칩니다.

**완료 상태:** 학교 서식 안에 선택 도서가 들어가고, 필요한 자리표가 학교명·금액으로 바뀝니다.

**기억할 점**

- 여러 표가 뒤섞인 시트보다 **한 개의 명확한 도서 표**가 적합합니다. 수서로는 한 개의 표를 골라 채웁니다.
- 도서 데이터 행의 가로 병합, 매크로·외부 연결·외부 호출 수식, 암호화 문서는 사용할 수 없습니다. 결재란 등 복잡한 양식은 단순한 사본으로 먼저 시험하세요.
- 기존 수식을 보존하고 조정하지만 모든 복잡한 수식을 보장하지 않습니다. Excel에서 파일을 열어 계산된 합계를 확인하세요. 요약 치환 표시를 쓰면 합계 숫자를 직접 채울 수도 있습니다.
- HWP/HWPX/PDF 학교 양식에 직접 채우는 기능은 없습니다. 입력 가능한 추천 문서 형식과 출력 가능한 학교 양식 형식을 구분하세요.

## 13. 자동 저장과 백업 파일 보관

**목적:** 평소 작업을 유지하고, PC 고장·교체에 대비한 별도 사본을 만듭니다.

### 자동 저장의 범위

책을 추가·수정할 때 **저장**을 누르거나, 목록에서 구입 체크를 바꾸면 PC의 자료에 반영됩니다. ISBN 조회로 추가에 성공한 책과 **○건 가져오기**를 마친 자료도 저장됩니다.

반면 **아직 저장하지 않은 수정 창의 입력**, **가져오기 전 미리보기의 수정**은 확정된 목록이 아닙니다. 필요한 저장·가져오기 동작을 마친 뒤 종료하세요.

### 백업 파일 만들기

1. **학교 설정 · 백업**을 엽니다.
2. **자료 백업과 복원 → 백업 파일 저장**을 누릅니다.
3. 내려받은 `.json` 파일이 저장되었는지 확인합니다.
4. 날짜와 업무를 알아볼 수 있도록 이름을 붙여 보관합니다. 예: `햇살초_2026-09-15_2학기발주전_백업.json`.
5. PC 고장에 대비하려면 학교에서 허용하는 별도의 저장 장치나 보관 위치에도 복사합니다.

| 백업에 포함 | 백업에서 제외 |
|---|---|
| 구입 목록, 도서 정보와 선택 상태, 학교명, 소장목록, 가져온 추천 원본, 등록한 학교 양식 | API 인증키, 별도로 내려받아 편집한 최종 발주서 파일 |

**완료 상태:** 수서로의 자료를 복원할 수 있는 백업 파일을 별도로 보관했습니다. 최종 제출한 발주서도 그 파일대로 함께 보관하면 좋습니다.

**기억할 점**

- 자동 저장은 별도의 외부 백업과 다릅니다. 정기적으로, 그리고 대량 가져오기·소장목록 교체·중요한 발주·PC 이동 전에 백업하세요.
- 기본 자료 위치는 `%LOCALAPPDATA%\Suseoro`입니다. Windows 탐색기의 주소창에 붙여 넣어 열 수 있습니다. 추천 원본은 `sources`, 양식은 `templates`, 복원 직전 백업은 `backups` 폴더에 보관됩니다.
- 백업에도 요청자 등 학교 업무 정보가 포함될 수 있습니다. 공개 GitHub나 공개 공유 링크에 업무 백업을 올리지 마세요.
- 원본 문서를 많이 보관하면 백업 용량도 커집니다. 용량 제한 오류가 나오면 원본 파일을 임의로 삭제하기보다 프로그램을 종료한 뒤 자료 폴더 전체를 별도 보관하고 도움을 요청하세요.
- 폴더를 직접 복사할 때는 먼저 수서로를 종료합니다. 실행 중인 자료 파일 일부만 복사하면 완전한 사본이 되지 않을 수 있습니다.

## 14. 백업 복원과 다른 PC로 이동

**목적:** 저장해 둔 시점으로 자료를 되돌리거나 새 PC에서 같은 업무를 이어갑니다.

### 백업 복원

1. 현재 자료도 보관해야 한다면 먼저 **백업 파일 저장**을 실행합니다.
2. **학교 설정 · 백업 → 백업 불러오기**를 누릅니다.
3. 수서로에서 만든 `.json` 백업을 선택합니다.
4. 표시된 파일명과 현재 자료 교체 안내를 읽습니다.
5. **현재 자료가 교체되는 것을 확인했습니다.**에 체크합니다.
6. **이 백업으로 복원**을 누릅니다.
7. 돌아온 화면에서 학교명·목록 수·도서·예산·등록 양식이 기대한 상태인지 확인합니다.

복원은 **현재 자료와 합치는 작업이 아니라 백업 시점 자료로 교체하는 작업**입니다. 현재의 여러 목록과 소장목록, 학교명·등록 자료가 영향을 받습니다. 이 PC에 등록한 인증키는 백업으로 옮겨지지 않습니다.

### 다른 PC로 이동

1. 기존 PC에서 수정·가져오기를 마치고 최신 백업을 만듭니다.
2. 백업 파일을 학교에서 허용하는 방법으로 새 PC에 옮깁니다.
3. 새 PC에 수서로를 설치하고 실행합니다.
4. 새 PC에 이미 업무 자료가 있으면 먼저 그 자료를 백업합니다.
5. 위 순서대로 옮긴 백업을 복원합니다.
6. 국립중앙도서관 인증키가 필요하면 새 PC에 다시 등록합니다.
7. 도서 목록·학교 양식·예산을 확인한 뒤 새 PC에서 작업을 이어갑니다.

### 잘못된 백업으로 복원했을 때

복원 직전 자료는 `%LOCALAPPDATA%\Suseoro\backups`에 `before-restore-…json` 파일로 따로 보관합니다. 파일의 수정 시각과 복원하려는 시점을 확인한 뒤 **백업 불러오기**로 그 파일을 선택해 복원할 수 있습니다. 파일이 여러 개라면 현재 자료도 먼저 별도 보관하고 신중히 선택하세요.

**완료 상태:** 원하는 시점의 학교 자료가 보이며, 새 PC에서도 같은 구입 업무를 이어갈 수 있습니다.

**기억할 점**

- 두 PC의 자료가 자동 동기화되지는 않습니다. 한 PC에서 계속 작업한 내용을 다른 PC에서 보려면 새 백업을 옮겨야 합니다.
- 각 PC에서 따로 수정한 목록을 백업 복원으로 자동 합칠 수는 없습니다. 어느 사본을 최종 기준으로 사용할지 정하세요.
- 수서로 1.x의 자료는 2.0에서 자동 변환하지 않습니다. 기존 수서 목록을 Excel/CSV로 저장한 뒤 **파일 가져오기**로 옮기고 검토합니다.
- 수서로 설치 폴더와 업무 자료 폴더는 다릅니다. 프로그램을 다시 설치하는 것만으로 원하는 백업 시점으로 돌아가지는 않습니다.

## 15. 업데이트와 프로그램 종료

**목적:** 새 버전을 확인하고 저장한 자료를 유지하면서 프로그램을 닫습니다.

### 자동 업데이트 — 2.0.2 이상 설치형

처음에는 자동 업데이트가 켜져 있습니다. 사용자가 꺼 둔 선택은 다음 실행에도 유지됩니다.

1. 수서로를 열면 뒤에서 새 버전을 확인합니다. **학교 설정 · 백업 → 업데이트 확인**으로 직접 확인할 수도 있습니다.
2. 자동 업데이트가 켜져 있고 새 버전이 있으면 설치 파일을 내려받고 검증합니다. 이 동안 평소처럼 작업하세요.
3. **수서로를 닫으면 새 버전이 자동으로 설치됩니다**라는 안내가 나타나면 준비가 끝난 것입니다.
4. 입력 중인 내용을 저장하고 수서로를 정상 종료합니다.
5. 설치가 끝난 뒤 다음에 수서로를 열면 새 버전으로 시작합니다.

프로그램이 작업 중에 스스로 닫히지는 않습니다. **학교 설정 · 백업**에서 자동 업데이트를 끌 수 있습니다. 자동 업데이트 설정은 이 컴퓨터에만 보관되며 학교 자료 백업과는 별개입니다. 무설치판은 자동 설치를 지원하지 않으므로 새 압축 파일을 받거나 설치형으로 전환하세요.

**2.0.0/2.0.1 사용자는 처음 한 번 새 버전으로 전환해야 합니다.** 구버전에는 자동 다운로드·종료 후 설치 기능이 없으므로 아래 순서로 업데이트하거나 최신 설치 파일을 실행하세요. 2.0.2 설치 이후부터 자동으로 적용됩니다.

### 새 버전 직접 확인·설치

1. 중요한 작업을 마치고 백업 파일을 보관합니다.
2. **학교 설정 · 백업**을 엽니다.
3. 버전 표시 옆 **업데이트 확인**을 누릅니다.
4. 새 버전이 있으면 **업데이트 설치**를 누릅니다.
5. 설치 창의 안내를 따라 마친 뒤 수서로를 다시 엽니다.
6. 버전과 기존 목록이 정상인지 확인합니다.

새 버전을 직접 확인하려면 위 버튼을 사용하세요. 준비된 업데이트에 **지금 업데이트**를 누르면 사용자의 선택으로 설치를 시작합니다. 자동 업데이트를 꺼도 이 수동 확인·설치는 사용할 수 있습니다. 버튼으로 설치할 수 없는 환경에서는 **설치 파일 다운로드 ↗** 또는 [공식 최신 배포 페이지](https://github.com/buildergarlic/suseoro/releases/latest)를 이용합니다. 인터넷 연결이나 파일 검증에 문제가 있으면 설치하지 않고 기존 프로그램을 계속 사용합니다.

### 수서로 종료

1. 열린 수정 창에서 필요한 **저장**을 마칩니다.
2. **학교 설정 · 백업 → 수서로 종료**를 누릅니다.
3. 브라우저 방식이라면 “수서로를 종료했습니다.” 안내가 나온 뒤 브라우저 탭을 닫습니다. 데스크톱 창 방식에서는 창을 닫아 종료할 수도 있습니다.

**완료 상태:** 업데이트 후 기존 목록을 다시 볼 수 있고, 종료 후 자료를 보관한 상태로 프로그램이 닫힙니다.

**기억할 점**

- 프로그램 파일과 자료는 별도 폴더에 보관됩니다. 앱을 제거해도 자료 폴더는 보존합니다.
- 브라우저 탭만 닫으면 뒤에서 실행 중인 수서로가 종료되지 않을 수 있습니다. **수서로 종료**를 사용하세요.
- 인터넷이 없으면 ISBN 조회와 업데이트 확인이 어렵습니다. 이미 저장된 목록의 수정·선택·파일 저장은 PC에서 할 수 있습니다.
- 업데이트 확인 실패는 저장된 수서 목록이 사라졌다는 뜻이 아닙니다. 연결을 확인하고 나중에 다시 시도하세요.

## 16. 1,500만 원 예산으로 업무 연습하기

**목적:** 실제 학교 구입 업무를 작은 연습 목록으로 한 번 끝까지 해 봅니다.

아래 책은 **모두 가상의 연습 자료**입니다. ISBN은 빈칸으로 두고 직접 입력합니다. 실제 도서 추천이나 가격 안내가 아닙니다. 연습용 목록은 실제 발주에 사용하지 마세요.

### ① 예산과 목록 준비

1. **새 목록 만들기**를 누릅니다.
2. 이름을 `연습 — 1,500만 원 수서`로 입력합니다.
3. 예산은 `15000000`, 할인율은 연습값 `10`으로 입력하고 저장합니다.

### ② 네 가지 후보를 직접 입력

**＋ 직접 추가**로 다음 네 행을 입력합니다. 제목·정가·수량을 정확하게 입력하고 네 행 모두 구입 선택합니다.

| 가상 연습용 책 | 정가 | 수량 | 할인 후 선택 금액 | 요청·메모 예시 |
|---|---:|---:|---:|---|
| 우리 반 작은 정원 | 15,000원 | 2권 | 27,000원 | 3학년 학생 요청, 자연 관찰 활동 |
| 질문으로 여는 과학 | 18,000원 | 3권 | 48,600원 | 과학교사 요청, 수업 연계 |
| 함께 읽는 옛이야기 | 12,345원 | 3권 | 33,333원 | 국어교사 요청, 함께 읽기 |
| 세계를 만나는 지도 | 22,000원 | 1권 | 19,800원 | 도서관 활동, 지도 자료 보완 |

**확인할 값:** 4종·9권, 구입 선택 금액 **128,733원**, 남은 예산 **14,871,267원**입니다.

### ③ 보류와 수량 변경 연습

1. `세계를 만나는 지도`의 구입 체크를 풉니다.
2. **보류** 탭에서 그 책을 확인합니다.
3. 예산 카드가 **3종·8권, 108,933원, 잔액 14,891,067원**인지 봅니다.
4. `질문으로 여는 과학`의 수량을 3권에서 2권으로 바꾸고 저장합니다.
5. **3종·7권, 92,733원, 잔액 14,907,267원**인지 확인합니다.

### ④ 미확인 가격 처리 연습

1. `우리 반 작은 정원`의 정가를 빈칸으로 바꾸고 저장합니다.
2. 가격 미확인 안내를 확인합니다. 이때 수량은 **7권**으로 남지만, 선택 금액은 해당 도서의 27,000원이 빠진 **65,733원**입니다.
3. **발주서 저장**을 열어 가격 확인 안내를 봅니다.
4. 창을 닫고 정가 `15000`을 다시 입력해 저장합니다.
5. 선택 금액이 **92,733원**으로 돌아오는지 확인합니다.

### ⑤ 발주와 백업까지 마치기

1. 구입 선택한 세 행의 제목·가격·수량·확인 필요 표시를 확인합니다.
2. **발주서 저장 → Excel → 수서로 기본 양식 → 발주서 저장**을 누릅니다.
3. 파일을 열어 **3종·7권, 92,733원**이 맞는지 확인합니다. 보류한 지도 책은 들어가지 않아야 합니다.
4. **학교 설정 · 백업 → 백업 파일 저장**으로 연습 자료를 보관합니다.

**완료 상태:** 도서 추가부터 예산 확인, 보류, 수량 조정, 가격 확인, 발주서, 백업까지 한 번씩 사용했습니다.

### 실제 1,500만 원 업무에 적용하는 질문

금액을 가득 채우는 것보다 **우리 학교에 필요한 근거가 있는 책**을 고르는 데 목록을 활용하세요.

- 학생 희망도서와 교사 수업 요청을 충분히 수집했는가?
- 특정 학년·분야에 치우치지 않았는가? 분류·대상·요청자를 기록해 살펴보았는가?
- 소장 도서와 겹치는 책은 복본·교체가 필요한 이유가 있는가?
- 판본·정가·수량을 확인했는가? 비싼 세트의 가격을 한 권 가격으로 잘못 넣지 않았는가?
- 지금 꼭 필요한 책과 다음 구입까지 기다릴 책을 구입 선택·보류로 나누었는가?
- 다른 학기·사업에서 쓴 금액과 합쳐 학교 연간 예산을 넘지 않는가?

수서로가 이 질문에 자동으로 점수를 매기거나 예산을 분야별로 배정하지는 않습니다. **요청자·대상·분류·우선순위·메모**에 판단 근거를 기록하면서 사서 선생님이 선택합니다.

## 17. 자주 묻는 질문과 문제 해결

문제가 생기면 먼저 지금 화면에 보이는 안내를 확인합니다. 자료를 바꾸는 조치 전에 현재 백업을 보관하면 되돌리기 쉽습니다.

| 상황 | 먼저 확인할 것과 해결 방법 | 해결되었는지 보는 방법 |
|---|---|---|
| ISBN을 넣었는데 책을 찾지 못해요 | 구입할 판본의 10/13자리 번호인지 확인합니다. 국내 도서는 인증키 설정을 확인하거나 직접 입력합니다. | 정확한 책이 추가되거나 직접 입력한 후보가 보입니다. |
| ISBN 조회 창을 닫았는데 책이 남아 있어요 | **조회하고 추가**는 성공한 책을 즉시 저장합니다. 필요 없으면 보류하거나 수정 창에서 삭제합니다. | 의도한 선택·보류 상태가 보입니다. |
| 제목은 찾았는데 가격이 없어요 | 무료 서지정보에 정가가 없을 수 있습니다. 확인한 정가를 직접 입력합니다. 미확인을 0원으로 바꾸지 마세요. | 가격 미확인이 사라지고 선택 금액이 반영됩니다. |
| 같은 책인데 내용이 다르게 보여요 | 제목만 보지 말고 ISBN·출판사·발행일·개정판 여부를 확인합니다. 잘못된 기존 값은 직접 수정합니다. | 구입하려는 판본과 정보가 일치합니다. |
| 예산은 남는데 발주서를 저장할 수 없어요 | 선택 도서의 제목·가격·ISBN·확인 필요 표시를 확인합니다. 가격이 없는 책은 잔액에 반영되지 않았을 수 있습니다. | 저장 전 안내를 해결하고 파일이 내려받아집니다. |
| 확인 필요 탭이 비었는데 저장 오류가 나요 | 잘못된 ISBN은 해당 탭에 항상 나타나지 않습니다. **구입 선택** 탭에서 ISBN을 점검합니다. | ISBN 오류를 고친 뒤 발주서가 저장됩니다. |
| 소장 도서가 자동으로 빠지지 않아요 | **학교 소장**은 확인 표시입니다. 복본이 필요 없으면 구입 체크를 직접 끕니다. | 보류로 이동하고 선택 금액에서 빠집니다. |
| 분명 소장한 책인데 표시가 없어요 | 최신 전체 소장목록인지, 양쪽 ISBN이 맞는지, 다른 판본인지 확인합니다. ISBN이 없으면 제목·저자도 봅니다. | 같은 판본이 비교되거나 별도 확인 사유를 기록했습니다. |
| 파일의 가격이 제목 칸에 들어갔어요 | 개별 수정 전에 **열 연결 확인 → 열 연결 적용**을 사용합니다. | 미리보기의 각 열이 맞게 정리됩니다. |
| 열 연결을 다시 적용했더니 수정이 사라졌어요 | 원본을 다시 읽은 결과입니다. 열 연결을 끝낸 뒤 개별 수정을 다시 진행합니다. | 열 연결과 수정값을 확인하고 가져오기를 마쳤습니다. |
| PDF·한글 문서에서 엉뚱한 행이 생겨요 | 원문을 보고 안내·합계행은 ×로 제외합니다. 어려운 파일은 간단한 표의 XLSX로 저장해 가져옵니다. | 미리보기 건수와 제목·ISBN·가격이 원본과 맞습니다. |
| 파일이 너무 크다고 해요 | 원본을 50 MB 이하로 나누거나 불필요한 이미지를 줄여 사본을 만듭니다. 소장목록은 전체 교체 특성상 전체 자료를 한 파일로 정리합니다. | 파일을 읽고 미리보기가 나타납니다. |
| 50권 조회를 반복해도 진도가 안 나가요 | 정가 등 빈값이 남은 앞쪽 행이 다시 대상일 수 있습니다. 파일을 작은 묶음으로 나누거나 확인한 값을 직접 입력합니다. | 해당 묶음의 빈 정보와 확인 상태를 정리했습니다. |
| 검색한 책만 발주하고 싶어요 | 검색은 선택을 바꾸지 않습니다. 검색어를 지우고 전체 선택 상태를 확인해 필요한 책만 체크합니다. | 발주서의 종수·권수와 대상이 의도와 맞습니다. |
| 삭제 취소 버튼이 없어졌어요 | 최근 삭제 알림을 닫거나 화면을 다시 열면 그 버튼은 남지 않습니다. 필요한 책을 다시 추가하거나 삭제 전 백업을 검토합니다. 백업 복원은 전체 자료를 교체합니다. | 필요한 도서가 올바른 목록에 다시 있습니다. |
| 학교 양식의 학교명이 바뀌지 않아요 | 고정 글자는 자동 교체하지 않습니다. 양식에 `{{school_name}}`을 쓰거나 출력 후 학교명을 고칩니다. | 결과 파일에 실제 학교명이 보입니다. |
| 학교 양식의 합계·인쇄가 이상해요 | 기본 양식으로 먼저 금액을 확인합니다. 학교 양식의 병합·수식·데이터 행을 단순화하고 출력 후 Excel에서 검토합니다. | 합계와 페이지 구성이 맞습니다. |
| 내려받은 파일을 못 찾겠어요 | 수서로의 저장 안내와 Windows의 다운로드 폴더, 브라우저의 다운로드 목록을 확인합니다. | 파일을 실제로 열 수 있습니다. |
| 다른 PC에서 목록이 안 보여요 | 설치만으로 자동 동기화되지 않습니다. 기존 PC의 백업 파일을 새 PC에서 복원합니다. | 기존 목록·학교명·양식이 보입니다. |
| 브라우저 탭을 닫았는데 계속 실행 중이에요 | 브라우저에서 방금 닫은 수서로 탭을 복원합니다. 보통 `Ctrl + Shift + T`나 방문 기록을 이용할 수 있습니다. 복원한 화면에서 **학교 설정 · 백업 → 수서로 종료**를 누릅니다. | 종료 안내를 확인한 뒤 탭을 닫았습니다. |
