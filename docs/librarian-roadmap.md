# 사서 업무를 위한 차기 업그레이드 제안

1. **교과·학년별 수서 계획**: 희망도서에 학년·교과·수업 주제를 연결하고 소장목록과 비교해 부족한 영역을 찾습니다. 성취기준을 직접 고르거나 학교 교육과정 파일에서 가져옵니다. 자동 추천 이유와 출처를 보여주고 최종 구입은 사서가 결정합니다.
2. **시리즈·복본·교체 도서 점검**: 시리즈의 빠진 권, 같은 판의 중복 구입, 오래된 정보서와 훼손 도서 교체 후보를 한 화면에서 관리합니다. 발행연도만으로 폐기 여부를 판단하지 않고 사서의 검토 상태를 보관합니다.
3. **월간 도서관 업무 보고서**: DLS에서 내보낸 대출·등록 통계와 수서 예산을 합쳐 학교 보고용 표와 그림을 생성합니다. 학생 이름·학번은 집계 전에 제외하고, 대출 건수와 소장 권수를 구분합니다.
4. **독서 행사 준비함**: 주제별 북큐레이션, 독서주간 일정, 전시 도서·준비물·업무 체크리스트와 안내문 양식을 저장합니다. 한 번 만든 행사를 다음 학기에 복사해 사용합니다.

다음 버전에서는 교과·학년별 수서 계획과 월간 보고서를 먼저 권합니다. 기존 구입목록·소장목록·통계를 그대로 활용할 수 있어 실제 업무 시간을 줄이기 쉽습니다.
