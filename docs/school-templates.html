학교 Excel 발주서 양식

발주서 저장 창에서 학교 양식 추가 (.xlsx)를 선택하세요. 한 번 저장한 양식은 다음 발주에도 사용할 수 있습니다.

  • 한 행에 열 제목을 적습니다. 예: 번호, 도서명, 저자, 출판사, ISBN, 정가, 수량, 할인율, 구입단가, 금액, 비고. 할인 후 한 권 금액을 넣으려면 구입단가를 쓰세요. 단가만 적으면 정가로 인식합니다.
  • 도서명 또는 ISBN 열이 있어야 합니다. 책을 알아보기 쉽게 두 열을 함께 넣는 것을 권합니다. 제목·서명, 저자·지은이, 출판사·발행처 등의 일반적인 표현을 인식합니다.
  • 열 제목 아래에 도서 한 권의 기본 행을 두면 그 행의 셀 서식을 이어 사용합니다.
  • 위쪽 학교명·제목과 아래쪽 합계·서명란은 유지하도록 처리합니다. 고정된 학교 이름은 자동으로 바뀌지 않습니다. 수서로 설정의 학교 이름을 넣으려면 해당 셀에 {{school_name}}을 적으세요. 병합 셀과 수식이 많은 양식은 저장 결과를 확인하세요.
  • 다른 형식의 양식은 먼저 Excel의 .xlsx로 저장해 사용합니다.

수서로 기본 양식을 먼저 저장하면 열 구성의 예시로 사용할 수 있습니다. 출력물은 선택한 도서만 포함합니다. 아직 확인하지 않은 가격이나 예산 초과가 있으면 저장 전에 안내합니다.

매크로 파일, 암호화 문서, 여러 개의 발주표가 한 시트에 뒤섞인 양식, 도서 데이터 영역의 복잡한 병합은 지원 범위 밖입니다. 원본 양식을 수정하지 않고 별도 발주서 파일로 저장합니다.

자동으로 채우는 값

양식 위·아래의 셀에 아래 표시를 넣으면 저장할 때 현재 목록의 값으로 바뀝니다.

표시 들어가는 값
{{school_name}} 학교 이름
{{list_name}} 구입 목록 이름
{{year}} 목록 연도
{{budget}} 목록 예산
{{order_total}} 구입 선택 금액
{{remaining}} 남은 예산
{{total_quantity}} 선택한 책의 총 수량
{{book_count}} 선택한 도서 행 수
{{discount_percent}} 목록 할인율

예를 들어 제목 셀에 {{school_name}} {{year}}년 도서 구입 목록이라고 적을 수 있습니다. 저장된 파일을 Excel에서 열고 학교 이름, 수량, 합계, 수식 결과, 인쇄 범위를 확인하세요. 여러 시트에 있는 모든 표가 자동으로 채워지는 것은 아닙니다.

단계별 사용법과 문제 해결은 상세 사용설명서를 참고하세요.
