# 추천목록을 한 번에 정리하기

추천 파일을 표준 양식으로 다시 만들 필요가 없습니다. **파일 가져오기**에서 여러 기관의 파일을 함께 선택하면 수서로가 열을 맞추고, 목록에 한 번에 추가합니다.

## 2.2.0 검토본 시작

압축을 푼 `Suseoro` 폴더의 **Start-Review.cmd**를 실행하면 브라우저에서 검토본이 열립니다. 자료는 `%LOCALAPPDATA%\Suseoro-Review-2.2.0`에 따로 저장되므로 기존 수서로의 학교 자료에 영향을 주지 않습니다. 빈 검토 목록에 샘플 파일을 가져와 시험할 수 있습니다. 종료할 때는 수서로 화면의 종료 버튼을 사용하세요.

## 여러 파일 가져오기

1. **파일 가져오기 → 추천도서 목록**에서 파일을 여러 개 선택합니다. 읽지 못한 파일은 이유를 표시합니다. 재시도하거나 해당 파일을 제외하고 계속합니다.
2. 각 파일의 **내용 확인**에서 원문 위치와 변환 결과를 살펴봅니다. 제목·저자·정가가 잘못 연결됐을 때만 **열 연결 확인**을 엽니다. 파일마다 다른 연결을 사용할 수 있습니다.
3. **같은 책 합치기**를 켜고 **N건 가져오기**를 누릅니다. 기존 목록과 새 파일 전체를 비교하며 신규 도서와 합친 추천 건수를 구분합니다.

추천 횟수와 구입 수량은 다릅니다. 합쳐도 수량을 늘리지 않으며 출처와 원문은 보존합니다. 다른 유효 ISBN, 권차·판 표시, 서지 또는 가격 충돌은 자동으로 버리지 않습니다. ISBN이 없는 책은 제목·저자·출판사·발행일이 정확히 맞는 경우에만 합칩니다. 제목만으로는 합치지 않습니다.

소장목록은 **학교 소장목록**에서 전체 파일 하나를 가져옵니다. 기존 소장목록을 교체하는 작업이므로 추천목록 통합과 구분합니다.

## ISBN 없이 진행하고 한꺼번에 확인하기

ISBN이 없는 구조화 목록도 제목·저자·출판사와 가격이 갖춰져 있으면 확인 필요로 분류하지 않습니다. 빈 ISBN 그대로 발주서를 만들 수 있습니다.

1. **ISBN 없음** 또는 **확인 필요** 필터로 모읍니다. 원문과 제목·저자·출판사를 비교합니다.
2. **작업** 체크로 대상을 고르거나 **검색·필터 결과 N건 전체 선택**을 누릅니다. 페이지를 넘어도 해당 결과 전체에 적용됩니다.
3. **서지 확인 완료**를 누릅니다. 200건도 한 번에 처리하며 구입 체크는 그대로 유지됩니다.
4. 가격 누락·잘못된 ISBN·불완전한 식별 정보는 건너뛰고 사유를 표시합니다. 수정한 뒤 다시 확인합니다.

**작업**은 이번 일괄 처리 대상, **구입**은 발주서에 넣을 책입니다. 검색어나 필터를 바꾸면 작업 대상 선택이 해제됩니다.

ISBN이 있는 책의 빈 서지를 채우려면 미리보기의 **ISBN으로 빈 정보 채우기**를 사용합니다. 한 번에 최대 50권이며 입력한 값은 유지합니다. 조회는 선택 기능이므로 인터넷 연결이나 인증키가 없어도 파일 통합·일괄 확인·발주를 계속할 수 있습니다. 제목 검색 결과의 ISBN을 임의로 붙이지 않습니다.

## 되돌리기와 큰 목록

가져오기 또는 일괄 확인·구입·보류 후 **되돌리기**로 최근 작업을 취소합니다. 이후 수정된 도서가 있으면 최신 편집을 보존하기 위해 되돌리지 않고 이유를 안내합니다.

미리보기와 도서 목록은 한 페이지에 100건씩 표시합니다. 추천 파일 저장은 합계 20,000건까지 지원합니다. 큰 목록은 회차별로 나누세요. 스캔 문서의 문자 인식은 엑셀보다 오래 걸릴 수 있으며 불확실한 원문은 확인 대상으로 남습니다.

선정·심의 시간은 자료 품질과 학교 절차에 따라 달라집니다. 이 기능은 파일 정리와 반복 확인을 줄이는 데 집중합니다.
