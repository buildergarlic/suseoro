# 수서로 2.0 — 사서 개인 PC용 수서 도구

## 목적
학교 사서가 별도 계정이나 서버 관리 없이 책을 모으고, 1,500만 원 기본 예산 안에서 학생·교사에게 필요한 책을 선택하고, 학교 발주서를 저장한다. 기존 v2의 승인·업체·납품 단계는 기본 제품 화면에서 제거한다. 수서 판단은 사서가 하며 프로그램이 예산을 임의로 채우거나 책을 자동 구매하지 않는다.

## 화면과 동작
- 바탕화면의 수서로 아이콘을 열면 현재 도서 구입 목록을 바로 보여준다. 학교 이름은 설정 한 곳에서 변경한다.
- 현재 목록, 예산·선택금액·남은금액, ISBN 추가, 파일 가져오기, 검색, 도서 표, 발주서 저장이 한 화면에 있다.
- 책을 구매/보류로 전환하고 제목·저자·출판사·ISBN·정가·수량·분류·요청자·대상·우선순위·메모를 수정한다. 삭제는 취소할 수 있다.
- 목록별 연도·예산·할인율을 관리한다. 기본 예산 15,000,000원, 기본 할인율 0%. 가격 미확인 자료와 예산 초과는 별도로 표시하고 최종 발주서는 확인된 자료만 허용한다.
- ISBN 체크숫자와 조회 결과 ISBN을 검증한다. 일치하지 않는 판본을 자동 채택하지 않는다. 무료 Open Library 기본 조회와 선택적인 국립중앙도서관 인증키를 지원한다. 없는 가격은 0원으로 처리하지 않는다.
- Excel/CSV/PDF/HWP/HWPX/DOCX/텍스트를 가져와 표준 열로 통합한다. 열 자동 인식이 어려우면 미리보기에서 연결한다. 원본 파일명·시트/쪽·행·경고를 보존한다. 스캔 PDF OCR과 불확실한 행은 확인필요로 남긴다.
- 소장목록 가져오기로 ISBN·서명/저자 중복을 표시한다. 추천기관 중복은 출처를 유지한다.
- 기본 발주서 XLSX/CSV와 인쇄용 HTML, 사용자 XLSX 양식에 맞춘 출력. 매크로 양식은 실행하지 않는다. 셀 수식 삽입을 막고 원본 양식을 보존한다.
- 자료는 사용자 LocalAppData에 자동 저장한다. 백업/복원, 목록별 데이터 분리, 외부 사이트로부터 로컬 API 보호, 업데이트 안내/설치를 제공한다.

## 구성
- 기존 React 화면 코드는 보존하되 진입점은 새 simple 화면으로 바꾼다.
- 새 FastAPI `suseoro.simple.app:create_app`와 SQLite `library.sqlite3`가 간단한 개인 수서 목록을 담당한다. 기존 복잡한 워크플로 코드와 검증된 파서는 공개 소스에 남긴다.
- PyInstaller + pywebview로 Windows 앱을 만들고 Inno Setup으로 사용자 권한 설치, 시작 메뉴/바탕화면 바로가기, 제거 기능을 제공한다. 브라우저 모드도 개발/호환용으로 제공한다.
- GitHub 공개 저장소에 소스, 재현 가능한 빌드, 자동 테스트, AGPL 라이선스, 사용설명, v2.0.0 설치 파일과 검증값을 공개한다. 사용자 자료·키·쿠키·개발 임시 파일은 제외한다.

기존 파서 회귀 테스트, 새 저장/수정/선택/예산/삭제취소/중복/백업/API 경계 테스트, 정확 ISBN 테스트, PDF·한글·엑셀 가져오기/학교양식 출력 테스트, React 테스트/브라우저 실제 수서 흐름, Windows 빌드와 설치 산출물 검증, GitHub 공개 다운로드 확인을 수행한다.
