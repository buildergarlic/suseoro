오른쪽 위 글자 크기에서 16·18·20을 고르고, 간결하게로 도서 행 간격을 바꾸세요. 목록에서 Ctrl+F로 검색하고, 책 제목이나 수정을 눌러 오른쪽에서 정보를 고칩니다. 고친 값은 저장으로 확정하세요.

ISBN 추가에서 국립중앙도서관 인증키 신청·등록을 안내합니다. 책 아래 알라딘 ↗ / 국립중앙도서관 ↗는 ISBN 검색입니다. 새 추천 양식 인식과 원문 확인 요령은 상세 설명서를 보세요.

02

ISBN이 있으면, 책부터 찾아요.

ISBN은 책의 이름표예요. 같은 제목이라도 판본이 다를 수 있으니 숫자를 확인해 주세요.

이해를 돕는 그림

숫자를 붙여 넣어요

ISBN 추가에서 조회하고 추가를 누르면 찾은 책이 현재 목록에 바로 추가돼요.

빠진 정보는 채워요

조회 창을 닫고 책의 수정에서 정가를 확인해요. 못 찾은 책은 직접 추가하고, 모르는 가격은 빈칸으로 남겨요.

국내 도서를 더 찾아요

학교 설정에서 국립중앙도서관 인증키를 등록할 수 있어요. 등록은 선택이에요.

조회 결과와 가격이 항상 모두 채워지는 것은 아니에요. 예정가격 또는 가격 미확인은 실제 구입할 책의 정가와 대조해 주세요.
한 가지만 기억하기무료 조회에는 인터넷이 필요해요. 찾지 못하면 확인한 책 정보를 직접 입력하면 됩니다.
03

살 책에 체크하면, 예산이 움직여요.

아래 가상 도서로 연습해 보세요. 체크를 끄면 보류가 되고, 수량을 늘리면 선택 금액이 커져요.

우리 학교 구입 바구니

연습용 가상 도서 3종 · 할인율 0% · 실제 자료에 저장되지 않아요.

전체 예산15,000,000원연습 예산
구입 선택 금액 · 확인된 금액48,000원3종 · 4권 선택
남은 예산 · 잠정14,952,000원미확인 가격은 계산에서 빠져요
  • 12,000원정가
    12,000원선택 금액
  • 18,000원정가
    36,000원선택 금액
  • 미정선택 금액

가격 미확인 1종. 확인된 48,000원만 계산했어요. 가격을 채우거나 해당 책을 보류해야 발주 준비가 끝나요.

가격을 채운 뒤 세 번째 책을 보류해 보세요. 잔액이 어떻게 바뀌나요?

인쇄본에서는 값을 바꿀 수 없습니다. HTML 설명서를 브라우저로 열면 구입 선택·수량·가격을 바꾸며 연습할 수 있습니다.

가격 빈칸은 0원이 아니에요. 아직 얼마인지 모른다는 뜻이에요. 실제 수서로에서도 미확인 가격은 합계에서 빠지며, 해당 책을 선택한 상태로 발주서를 저장할 수 없어요.
실제 수서로에서는구입 체크로 선택하고, 책 제목이나 수정을 눌러 수량과 정가를 바꿔요. 이 설명서에서는 실제 발주서를 만들지 않아요.

05

제각각인 추천 파일을 한 줄씩 정리해요.

파일을 읽은 뒤 미리보기를 확인하고 가져와요. 원본에 없는 정보는 사서 선생님이 확인해 채워 주세요.

이해를 돕는 그림

  1. 파일 가져오기
    추천도서 목록을 선택해요.
  2. 열 연결 적용
    엉뚱한 칸에 들어갔다면 연결을 고쳐요.
  3. 상세 → 원문 보기
    불확실한 행을 고쳐요.
  4. ○건 가져오기
    읽어 온 건수를 확인해 담아요.
스캔 PDF와 복잡한 한글 문서는 확인이 더 필요해요. 책 제목·정가·수량을 원문과 비교해 주세요. 열 연결을 다시 적용하면 원본을 다시 읽으므로, 미리보기에서 고친 내용이 다시 채워집니다.

학교 소장목록

학교가 이미 가진 책을 대조하는 자료예요.
기존 소장목록 전체를 새 파일로 교체해요.

한 가지만 기억하기추천 파일은 “후보 더하기”, 학교 소장목록은 “학교가 가진 책 명단 바꾸기”예요.
06

노란 표시는, 한 번 더 살펴보라는 뜻이에요.

프로그램이 책을 대신 고르지는 않아요. 표시를 참고해서 필요한 책인지 직접 결정해 주세요.

이해를 돕는 그림

확인 필요→수정→원본 파일과 실제 책 정보 대조→확인 필요 표시해제 후 저장

학생에게 필요한가요?

학생 희망도서, 읽기 수준, 관심 분야를 살펴요.

수업에 도움이 되나요?

교사의 요청, 교과 연계, 필요한 권수를 살펴요.

선정 이유를 남겨요

요청자·대상·우선순위·메모를 적으면 나중에 다시 고르기 쉬워요.

발주 전에는 제목·ISBN 형식·정가·확인 필요·예산 초과를 해결해 주세요. ISBN을 모르는 책은 비워 둘 수 있지만, 잘못 입력한 ISBN을 그대로 두면 발주할 수 없어요.
한 가지만 기억하기확인 표시를 지우는 것만으로 정확해지지는 않아요. 내용을 확인하고 수정한 뒤 해제해 주세요.

PDF는 인쇄용 파일을 열어서 저장해요. 브라우저 인쇄에서 “PDF로 저장”을 선택해 주세요. 한글 파일은 추천 목록을 읽어 오는 형식이며, 발주서를 HWP·HWPX로 직접 저장하는 기능은 없어요.
한 가지만 기억하기파일 저장은 서점으로 주문을 보내는 동작이 아니에요. 완성된 파일을 확인하고 학교의 발주 절차에 따라 사용해 주세요.
08

자동 저장은 이 PC에, 백업은 따로.

평소에는 자동 저장돼요. 입력창에서는 저장을 눌러 확정해요. PC를 바꾸거나 중요한 작업을 마친 날에는 백업 파일도 보관해 주세요.

이해를 돕는 그림

백업 파일 만들기

학교 설정 · 백업 → 백업 파일 저장
저장한 JSON 파일을 학교 규정에 맞는 안전한 장소에 보관해요.

백업으로 돌아가기

백업 불러오기 → 파일 확인 → 이 백업으로 복원
현재 자료를 교체하는 작업이니 파일 이름과 날짜를 확인해요.

복원은 합치기가 아니라 교체예요. 현재 모든 목록과 소장목록, 학교 설정을 백업 자료로 바꿔요. 복원 직전 자료는 자동으로 별도 백업됩니다. 인증키는 백업되지 않으므로 새 PC에서는 다시 등록해 주세요.
새 버전 확인:학교 설정 · 백업→업데이트 확인→업데이트 설치
한 가지만 기억하기발주서 파일은 구입 결과이고, 백업 파일은 작업 자료를 되살리는 열쇠예요. 둘 다 보관해 주세요.
