# 수서로 2.2.1 — 숫자 입력 수정

## 바뀐 점

- 목록 설정의 연도·예산·할인율을 수정할 때 기존 숫자를 모두 지우면 0이 대신 들어가던 문제를 고쳤습니다. 입력을 지우고 원하는 숫자를 다시 입력해 저장할 수 있습니다.
- 2.2.0의 추천 파일 통합과 ISBN 없는 도서의 일괄 검토 기능도 포함합니다.

## 기존 사용자 업데이트

자동 업데이트가 켜진 Windows 설치형 2.0.2 이상은 새 버전을 내려받아 검증하고, 수서로를 정상 종료한 뒤 설치합니다. 기존 목록과 설정은 유지됩니다. 이미 실행 중이면 **학교 설정 · 백업 → 업데이트 확인**을 누르세요.

무설치판과 2.0.0/2.0.1, 1.x는 [최신 공개 버전](https://github.com/buildergarlic/suseoro/releases/latest)에서 직접 새 버전을 받으세요.

## 다운로드

- 설치판: `Suseoro-Setup-2.2.1.exe`
- 무설치판: `Suseoro-Portable-2.2.1.zip`
- 오프라인 설명서: `Suseoro-Guide-2.2.1.zip`
- 다운로드 파일과 `.sha256`, `SHA256SUMS` 체크섬을 함께 제공합니다.
