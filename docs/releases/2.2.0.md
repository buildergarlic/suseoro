# 수서로 2.2.0 — 추천목록 통합과 일괄 검토

여러 기관의 추천도서 목록을 한 번에 정리하고, ISBN 없는 도서를 반복해서 확인해야 하는 수고를 줄였습니다.

## 바뀐 점

- 여러 추천 파일을 함께 선택하고 파일별 열 연결·수정·재시도 후 한 번에 가져옵니다. 별도의 표준 엑셀을 먼저 만들 필요가 없습니다.
- 같은 책을 합치면서 추천 출처·원문·추천 횟수를 보존합니다. 중복 추천이 구입 수량을 늘리거나 기존 편집을 덮어쓰지 않습니다.
- 제목·저자·출판사·가격이 갖춰진 자료는 ISBN이 없어도 진행할 수 있습니다. 잘못된 ISBN·가격 누락·불확실한 원문은 확인 대상으로 남깁니다.
- 검색·필터 결과 전체를 선택해 서지 확인·구입·보류를 일괄 처리하고 최근 작업을 되돌릴 수 있습니다. 작업 대상 선택과 구입 선택은 구분됩니다.
- 목록과 미리보기는 100건씩 표시하며 한 번에 최대 20,000행을 저장합니다. 통신 재시도로 생기는 중복 입력을 방지합니다.

## 기존 사용자 자동 업데이트

자동 업데이트가 켜진 정식 설치판 **2.0.2 이상**은 시작할 때 새 버전을 확인하고 검증된 설치 파일을 내려받습니다. 준비가 끝난 뒤 수서로를 정상 종료하면 설치되며 다음 실행부터 2.2.0을 사용합니다. 수서 목록·소장 자료·설정은 유지됩니다.

이미 실행 중이면 **학교 설정 · 백업 → 업데이트 확인**으로 새 버전을 확인할 수 있습니다. 작업 중인 창을 강제로 닫지 않습니다. 자동 업데이트를 꺼 둔 경우 수동으로 업데이트할 수 있습니다.

2.0.0/2.0.1은 업데이트 설치 버튼 또는 새 설치 파일로 전환하세요. 무설치판과 1.x는 자동 설치 대상이 아닙니다. 1.x 자료는 Excel/CSV로 내보낸 뒤 새 수서로에서 가져오세요.

## 다운로드

- Windows 10/11 64비트 설치판: `Suseoro-Setup-2.2.0.exe`
- 무설치판: `Suseoro-Portable-2.2.0.zip`
- 오프라인 사용설명서: `Suseoro-Guide-2.2.0.zip`
- 각 파일의 `.sha256` 및 `SHA256SUMS`를 함께 제공합니다.

[상세 사용설명서](https://buildergarlic.github.io/suseoro/user-guide.html)에서 여러 파일 통합과 ISBN 없는 책의 일괄 확인 방법을 확인하세요.
