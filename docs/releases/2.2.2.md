# 수서로 2.2.2 — 더 넓어진 도서 작업 화면

## 바뀐 점

- 목록·예산·주요 작업을 왼쪽 메뉴에 모으고 도서 표가 창의 남은 높이를 사용하도록 바꿨습니다. 한 화면에서 더 많은 책을 살펴보고 검색·필터·수정을 이어갈 수 있습니다.
- **등록 자료 → 학교 소장목록**에서 마지막에 등록한 소장자료를 검색하고 페이지를 넘기며 확인할 수 있습니다. 소장 비교는 계속 구입 목록에서 확인합니다.
- **등록 자료 → 추천도서 목록**에서 현재 구입 목록에 저장된 도서를 추천 출처별로 검색하고 볼 수 있습니다. 이 화면은 원본 추천 파일이나 업로드 이력 목록이 아닙니다.
- 작은 창에서는 왼쪽 메뉴를 열고 닫아 도서 표 공간을 확보합니다.
- 2.2.0의 여러 추천 파일 통합과 일괄 검토, 2.2.1의 숫자 입력 수정도 포함합니다.

## 기존 사용자 업데이트

자동 업데이트가 켜진 Windows 설치형 2.0.2 이상은 새 버전을 내려받아 검증하고, 수서로를 정상 종료한 뒤 설치합니다. 기존 구입 목록·학교 소장자료·설정은 유지됩니다. 이미 실행 중이면 **학교 설정 · 백업 → 업데이트 확인**을 누르세요.

무설치판과 2.0.0/2.0.1, 1.x는 [최신 공개 버전](https://github.com/buildergarlic/suseoro/releases/latest)에서 직접 새 버전을 받으세요.

## 다운로드

- 설치판: `Suseoro-Setup-2.2.2.exe`
- 무설치판: `Suseoro-Portable-2.2.2.zip`
- 오프라인 설명서: `Suseoro-Guide-2.2.2.zip`
- 다운로드 파일의 `.sha256` 및 `SHA256SUMS` 체크섬을 함께 제공합니다.
