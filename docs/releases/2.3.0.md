# 수서로 2.3.0 — 우리 학교 책숲과 업데이트 복구

## 업데이트 연결 개선

- 학교망의 자동 프록시(PAC)와 Windows 인증서 설정을 따르는 통신으로 재시도합니다.
- GitHub API가 막히거나 조회 한도를 넘으면 공식 릴리스의 `update.json`에서 새 버전을 확인합니다. HTTPS, 공식 저장소 주소와 SHA-256 검증을 유지합니다.
- DNS·프록시·인증서·시간 초과·학교망 차단·GitHub 조회 한도 오류를 구분해 안내합니다.
- 업데이트 오류 진단 요약을 Netlify 수신 폼을 통해 `buildergarlic@gmail.com`으로 자동 보고합니다. 같은 오류는 하루 한 번 보고하며, 연결이 끊기면 PC에 보관했다가 재시도합니다. 학교 설정에서 켜기·끄기와 시험 보고를 할 수 있습니다.
- 보고에는 앱/OS 버전, 발생 시각, 오류 단계·종류·코드, 임의 설치 식별자만 포함됩니다. 도서 목록·학교 이름·계정·인증키·원본 로그는 전송하지 않습니다.

**기존 버전이 업데이트 서버에 연결하지 못하는 PC는 이번에 설치 파일을 직접 받아 설치해 주세요.** 새 연결 경로는 2.3.0 설치 후부터 사용됩니다. 학교망이 GitHub 전체를 차단하면 네트워크 관리자에게 공식 배포 도메인 접근을 요청해야 합니다. 학교 PC의 실제 원인은 해당 PC 오류 코드로 확인해야 합니다.

## 내 구입 목록 관리

- 각 구입 목록 옆에서 이름·연도·예산·할인율을 수정하고 목록을 삭제할 수 있습니다.
- 삭제는 자료를 보관하는 방식입니다. 즉시 취소하거나 ‘삭제한 목록’에서 복원할 수 있습니다. 마지막 목록은 삭제하지 않습니다.

## 우리 학교 책숲

- 소장목록의 권수와 등록 건수, ISBN 수, 분야별 분포, 소재별 키워드, 출판연도, 주요 출판사를 귀여운 책숲 대시보드로 보여드립니다.
- ISBN 도서정보 보완은 진행률을 표시하며 중지·다시 시작할 수 있습니다. 국내 도서는 학교 설정의 국립중앙도서관 인증키를 등록하면 조회에 도움이 됩니다. 가져온 원본 소장자료는 덮어쓰지 않습니다.
- 분야는 등록된 분류기호와 조회된 서지정보를 집계합니다. 소재는 제목·주제어의 키워드 추정이며 책 본문 전체를 분석한 결과가 아닙니다. 미분류와 정보 부족 건수를 함께 표시합니다.

## 다운로드

- 설치판: `Suseoro-Setup-2.3.0.exe`
- 무설치판: `Suseoro-Portable-2.3.0.zip`
- 오프라인 설명서: `Suseoro-Guide-2.3.0.zip`
- 자동 업데이트 정보 `update.json`과 각 파일의 SHA-256 검증값을 함께 제공합니다.
