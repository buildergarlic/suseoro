# 수서로 2.2.3 — 처음부터 따라 하기 쉬운 설명서

## 바뀐 점

- 앱에서 **사용설명서**를 열면 **처음 따라 하기**가 먼저 표시됩니다. 연습용 목록을 만들고 책 한 권을 담아 구입 체크와 예산 변화를 확인한 뒤 발주서와 백업 파일을 저장하는 순서로 안내합니다.
- 각 단계에 화면에서 확인할 결과를 적고, 설명서를 새 창으로 열어 수서로와 나란히 볼 수 있게 했습니다. **그림 안내**와 **상세 설명서**도 설명서 창에서 선택할 수 있습니다.
- 오프라인 설명서 첫 화면에서도 **첫 10분 따라 하기**로 바로 이동할 수 있습니다. 다운로드한 설명서 ZIP의 HTML 파일을 같은 폴더에 풀면 인터넷 없이 읽고 연습할 수 있습니다.
- 2.2.2의 왼쪽 메뉴·넓어진 도서 표·등록 자료 열람을 포함합니다. 저장 자료 형식은 바뀌지 않습니다.

## 기존 사용자 업데이트

자동 업데이트가 켜진 Windows 설치형 2.0.2 이상은 새 버전을 내려받아 검증하고, 수서로를 정상 종료한 뒤 설치합니다. 기존 구입 목록·학교 소장자료·설정은 유지됩니다. 이미 실행 중이면 **학교 설정 · 백업 → 업데이트 확인**을 누르세요.

무설치판과 2.0.0/2.0.1, 1.x는 [최신 공개 버전](https://github.com/buildergarlic/suseoro/releases/latest)에서 직접 새 버전을 받으세요.

## 다운로드

- 설치판: `Suseoro-Setup-2.2.3.exe`
- 무설치판: `Suseoro-Portable-2.2.3.zip`
- 오프라인 설명서: `Suseoro-Guide-2.2.3.zip`
- 다운로드 파일의 `.sha256` 및 `SHA256SUMS` 체크섬을 함께 제공합니다.
