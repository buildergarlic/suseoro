# 수서로 2.2.6 — 업데이트 오류 진단 개선

## 바뀐 점

- 업데이트 확인과 다운로드에 실패하면 오류 종류와 HTTP 상태를 `%LOCALAPPDATA%\Suseoro\desktop.log`에 기록합니다. URL, 계정 정보, 서버 응답 내용은 기록하지 않습니다.
- 모든 실패를 인터넷 연결 문제로 안내하던 문구를 수정했습니다. 실패해도 기존 수서로와 학교 자료는 유지됩니다.

학교 PC에서 같은 오류가 나면 `Win + R`을 누르고 `%LOCALAPPDATA%\Suseoro\desktop.log`를 열어 `GitHub release check failed` 또는 `Update download failed` 줄을 확인해 주세요. 자동 이메일 발송 기능은 아직 제공하지 않습니다.

## 기존 사용자 업데이트

자동 업데이트가 켜진 Windows 설치형 2.0.2 이상은 새 버전을 내려받아 검증하고, 수서로를 정상 종료한 뒤 설치합니다. 현재 PC에서 GitHub 접속이 막혀 있다면 [최신 공개 버전](https://github.com/buildergarlic/suseoro/releases/latest)의 설치 파일을 다른 PC에서 받아 직접 설치해 주세요. 기존 목록과 설정은 유지됩니다.

## 다운로드

- 설치판: `Suseoro-Setup-2.2.6.exe`
- 무설치판: `Suseoro-Portable-2.2.6.zip`
- 오프라인 설명서: `Suseoro-Guide-2.2.6.zip`
- 다운로드 파일의 `.sha256` 및 `SHA256SUMS` 체크섬을 함께 제공합니다.
