# 수서로 2.2.4 — 선택한 책을 한꺼번에 삭제

## 바뀐 점

- 도서 표의 **작업** 체크로 여러 권을 고른 뒤 **일괄 작업 → 선택한 책 삭제**를 누를 수 있습니다. 현재 페이지 또는 검색·필터 결과 전체를 한 번에 선택할 수도 있습니다. **작업** 체크는 발주 여부를 정하는 **구입** 체크와 별개입니다.
- 확인 창에 삭제할 건수와 책 이름을 표시합니다. 확인한 책은 현재 구입 목록과 등록된 추천도서 목록에서 사라지고, 예산 계산에서도 빠집니다. 학교 소장목록은 유지됩니다.
- 삭제 직후 **일괄 작업 → 되돌리기**로 같은 책들을 함께 복원할 수 있습니다. 이후 다른 작업으로 책이 바뀌었다면 최신 수정을 보호하기 위해 되돌리기를 거절합니다.
- 기존 한 권씩 **이 책 삭제**하는 기능도 계속 사용할 수 있습니다. 저장 자료 형식은 바뀌지 않아 기존 목록·설정·추천 원본을 그대로 사용합니다.

## 기존 사용자 업데이트

자동 업데이트가 켜진 Windows 설치형 2.0.2 이상은 새 버전을 내려받아 검증하고, 수서로를 정상 종료한 뒤 설치합니다. 기존 구입 목록·학교 소장자료·설정은 유지됩니다. 이미 실행 중이면 **학교 설정 · 백업 → 업데이트 확인**을 누르세요.

무설치판과 2.0.0/2.0.1, 1.x는 [최신 공개 버전](https://github.com/buildergarlic/suseoro/releases/latest)에서 직접 새 버전을 받으세요.
